# v80 整体骨架与公共内容发布

本轮按用户最新要求把工作收拢到系统主干：已有标题、地图与事件、战斗往返、持有菜单、经济成长和存档续行使用同一运行时；不再沿着下一个 NPC 或镜头开展主线研究。

## 交付

公共内容构建改为纯候选编译、整批闭包检查、一次发布。基础包和普通敌队准备后，其余独立包可以并行准备；下游使用本次敌队候选。任一准备、摘要、地图身份或媒体闭包失败，都不会替换原公开内容集合。独立来源包保留，来源包公开 writer 与主管线共用锁。具体合同见 [统一内容管线](content-package-pipeline.md)。

地图身份检查从 Repository 提取为共用接口，运行时、批量候选和版本归档使用相同 map/area/source 绑定规则。未知的执行 profile 仍可按正确身份保留在完整归档，不因此授予可执行资格。

前一工作段已完成的演员事务和通用脚本移动在本轮收尾：私有状态草稿保留正在运动的原演员，未变的演员保持原引用；修改活动运动仍被拒绝。MoveTo 复用既有 VM、演员运动和事件等待，验证双演员并行、合流、菜单、保存恢复及后续输入，不增加第二套运动或事件内核。已编译的 97 个来源地图预览保持本地私有，本轮没有转向地图数量扩张或自主 NPC 控制器调查。

## 验收

当前构建的真实结果记录在 ignored `build/reports/v80-validation-summary.json`。日常门禁仍为六组、七个代表性检查器，不为每条指令增加一个骨架前置项。新增候选及发布测试覆盖失败保留、依赖误绑、独立包保留、并发拒绝、上游变更和发布后的归档失败。

本轮源码检查 3164/3164、Python 43/43 与原生绑定测试 16/16 通过；六组骨架的 112 个受控案例通过。实际主管线完成 8 个公共包的一次整体发布，原 43 个文件和独立来源批次的 8 个文件全部保留原字节。版本续行 14 个、音频版本 6 个、来源往返 8 个案例通过；HTTP 壳、内容引用和原 PNG/FLAC 的 5 项检查通过。来源批次仍保留 14 条依赖诊断，完整准入按预期阻塞。

完整来源主线仍未迁移；受控运行及 DOM/媒体替身没有完成实际浏览器或原版一致性验收。全 Web 迁移 goal 继续 active，HD-2D 后置。

后续继续以公共系统合同为实施单位。成组地图、事件和敌队通过既有依赖工作单进入此管线；特殊技能、NPC 或精细演出只有实际阻塞选定批次时才进入实现队列。
