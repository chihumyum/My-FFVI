# 普通 CounterAct 的自身目标分支

该增量按完整共同分支迁移普通 `CounterAct` 的 range5。没有新增敌队、场景或 PC 特判，也没有授予步行遇敌准入。原程序、其它 AI 指令、技能效果、初始状态、动态参与者和活跃脚本动作的依赖保持独立。

全源提名保留 3304 份程序 / 186003 条指令、430 份 MonsterAI / 10093 条指令、53 份战斗脚本 / 2312 条指令。233 个 CounterAct 站点中，203 处引用自身范围技能，分布于 111 份完整 AI、37 条技能记录。131 个相关依赖敌队、62 个步行池敌队及 91 张池地图都是静态范围，不是可玩数量。原战斗脚本辅助器的 490 请求、与全部原始步行池引用取并集后的 492 请求，以及实际世界 producer 自己收集的请求，是不同清单，不能相互替代或据此推断 producer 漏项。

## 原生证据与执行边界

同一来源 DLL 的 `CounterAct 0x81fd50` 在原权重抽样后读取技能范围；`IsSelf 0x3d59d0` 精确判断 range5。该分支传入 null 目标列表，`SetActAbilityCounter 0x15b8550` 保留 Interrupt 类型和 counter 标记；`SetActData 0x15b9d80` 再通过 `GetAttackTargetDecision 0x15b94a0` 选择当前实际行动者。非自身的普通反击继续使用实际收到攻击者。本次复核已有五个完整缓存方法和 2656 字节 PE，没有追加反编译，也没有原版动态一致性结论。

`SetActData` 在自动目标分派前检查混乱。现有普通 Web 控制状态 owner 尚未闭合受控反击的完成协议，因此本次新增的普通自身反击在活跃混乱或诱惑状态下明确拒绝。不能因为能计算自身目标便忽略实际控制 owner。普通其它未恢复范围、未知目标来源或缺失身份也继续阻断。

## 共用 owner 与事务

`battle-ai-targets` 同时为编译器和运行时验证精确 range/rule；`sourceCounterTargeting` 仅在技能抽样之后把普通自身分支转为既有 automatic 策略。显式自动选目标的 `CounterActReceiveCommand` 沿用原合同，普通 range3/7 则保留攻击者策略。来源 AI 本文和 PC 不改变。

`BattleGame` 仍持有当前实例、行动引用、行动条、普通与反击队列、费用、效果和随机流。自身选择读取本次结算后暂存的实际受击敌人，沿用自动目标 provider，既不读取永久名册来猜实例，也不把攻击者、怪物 master 或来源槽当自身。排队动作携带已有 automatic 字段，在准备及命中时复核实际身份。源权重抽样保留；自身不增加目标随机抽样。已退休的行动者取消旧动作，后来占据同一槽的新实例不会继承反击。

父攻击的所有伤害、MP、状态、反应 AI、行为变量、行动登记和随机流仍在原事务中一起提交。后续接收者、技能或活跃控制依赖失败，整次动作回滚并允许同一未消费帧重试。反击结束不清普通行动条、不推进普通表行，也不递归唤醒普通反击。

`GameSession` / `GameBattleHandoff` 继续负责原入战票据、取消失败与一次返场；没有新持久队列或存档权限。稳定返场后使用既有 Storage 保存和恢复，下一次遭遇创建新的战斗 owner。

## 验证口径

`tests/battle-self-counter.test.ts` 覆盖实际自身恢复、费用、普通队列保留、混合加权分派、帧切分重放、后续接收者失败整次回滚、活跃控制/未知范围阻断及同槽替换退休。

`tests/battle-self-counter-session.test.ts` 使用真正的新游戏初始化、来源遭遇请求、Flow、Commands、准备交接和 Storage。全部资源在启动前声明；驱动没有在启动后改写 HP、名册或 AI。它验证入战准备失败重试、自身反击、胜利返场失败重试、一次结算、字段继续、保存恢复及第二场战斗。

`scripts/check-source-self-counters.mjs --before <独立编译的基线 dist>` 在同一来源输入上保存全部 430 份 AI 和 53 份战斗正文，并对 203 处原操作数进行受控唤醒/抽样边界检查；其受控短正文不算原完整 AI 执行。490 与 492 两组都使用相同 participant closure、策略与完整依赖前后比较，只允许消除已证明的自身反击目标诊断，禁止删改其它门槛。来源技能有未实现效果时仍保留原 blocker。该工具只写 ignored 报告，不生产地图或发布内容。

合成机制检查、原参数探针、完整原程序执行、真实浏览器游玩与原版对照分别计数。此增量没有完成原故事或全游戏验收。
