# 系统集成 v35

本批推进共用效果资源寿命、来源粒子引擎子核和效果板合成。Web 迁移仍优先于 HD-2D；没有增加地图名、剧情或坐标专用分支。来源开场所需的五个完整粒子发射器仍未放行，不能用这些系统增量宣称 Map3 或全游戏已经可玩。

## 共享效果资源与切图

`WorldSession` 在有显式候选宿主时持有唯一 `FieldEffects` 管理器。每张地图只租用自己的板，局部 EntityID 经地图租约编码后进入共享池。普通切图先在私有候选中完成旧资源缓存释放与板引用退休，再准备新板和初始化指令；整个阶段只在最终提交时发布一次。失败、取消、状态过期和竞争候选均丢弃私有资源，浏览器加载图片或音频失败也调用 `discard`。

全局 camera ID、位置分配计数和媒体身份不会因换图或空地图而重置。已退休的 FieldGame 保留只读快照，不能再推进当前效果池。`commitWith` 在队伍与库存提交之前完成全部效果验证，并在两者发布期间锁住效果所有者；不在库存已更新后再次运行可能失败的宿主验证。宿主违反预备提交不得失败的契约时，管理器停止复用，会话明确停止，不虚报已回滚外部系统。

正在校验的切图仍保留取消记录。宿主校验回调中的取消只标记候选，回调退出后才清理资源；在队伍与库存开始提交之前再次核对取消状态。不能因为从待加载表删除了记录，就让取消失效或在忙碌的宿主回调内重入清理。

同一条 Ready 同时显示相机与效果板时，也使用联合提交：全部效果校验和相机版本校验完成后，再发布演员、任务、相机与效果状态。实体组激活同样在图块注册前完成效果校验。这修复了相机或图块先变化、第二次效果校验随后拒绝造成的部分写入；三条修复前失败回归分别覆盖这两个路径和切图取消。

来源 `MapCleanTask` 先调用 `MapClean/ClearCurrentMap` 再 yield，随后才进入 LoadMap。`ClearMapAsset` 清除 prefab/shared lookup；Unity 对象销毁释放板引用。这支持普通 clear/load 分支的终态顺序，不是原生销毁回调时序的实测。保留地图、复制地图、常驻 FX、事件组 FX、完整粒子存档继续有独立门禁。初始原生会话也不能在演员安装之前提前发布 FX。参见 [候选事务](field-effect-transactions.md)。

菜单操作与存档编码条件分开：空闲且有效的地图可使用普通道具和换装；活动事件、移动、战斗与来源准备继续限制这些操作。FX 或历史分配状态缺少完整存档编码时仍不能保存，即使当前已进入没有效果板的地图。

## 来源粒子引擎与渲染

已取得与本机 `UnityPlayer.dll` 完全匹配的官方 PDB，版本为 `2019.4.20f1_6dd1c08eedfa`，CodeView GUID/age 为 `4420B376-89DD-4CFE-AEC8-2300F4A999D2 / 1`。随机流、种子重置、时钟与普通常量发射子链从该二进制恢复，并用隔离的 x64 函数执行结果对照。操作系统熵决定的自动初态必须显式输入，不能用固定零或 `Math.random` 冒充来源。详见 [粒子引擎子核](field-particle-emitter.md)。

粒子 shader 顶点转换、源相机与效果板材质分别恢复。效果板实际使用 `FieldEffectEntityShader` 的两个 pass，共享普通字段的颜色、深度与瞬态 stencil 附件；不能在 Canvas 最后叠一张透明图代替。两 pass 的丢弃条件并不互斥，深度写入规则也不同。渲染入口要求显式提供粒子帧和板绘制顺序，缺依赖就拒绝整帧。

编译、宿主接口和绘制次序见 [粒子几何与效果板合成](field-particle-geometry.md)。

这些模块不等于完整 Unity ParticleSystem。Noise、Cone 采样、预热与运动积分、实际 billboard 展开/排序和粒子 RT 色空间仍待闭合。真实粒子 RT 请求 ARGB32、sRGB 和零深度位，不能直接套普通字段的深度纹理配置。五个实际发射器仍保持不可执行，现有来源开场在目的地图效果提供器处停止。

## 验证与后续

验证记录保存于忽略目录 `build/reports/systems-v35-*`，包含内核/事务测试、原生字节绑定、真实来源编译、隔离函数对照与浏览器检查。静态反编译保留 `semanticsVerified=false`；隔离函数执行不等于运行原版游戏。源码、工具、文档与合成测试同步到私有 GitHub，PDB、原游戏文件、提取资源和生成包留在本机。

最终 `npm run check` 通过 1,415 项测试及知识契约校验；Python 26 项与依赖检查通过，111 条来源/运行时/受控界面命令全部通过。新增来源证据包括 14 个地图清理方法与 11 条语义绑定、166 项引擎绑定检查、602 项发射内核检查、72 项几何原生绑定与 551 项几何/材质来源检查。602 项中包含 394 次原 DLL 隔离指令结果对照。受控纹理和 DOM 结果分别保留，不能代替真实粒子或浏览器帧。
