# v65 公共内容执行与战斗决策

本批按游戏骨架优先收口两个公共接口：批次执行与网页应用使用同一套启动、命令和战斗交接；不同敌人的普通目标决策接入既有队列和结算。没有增加场景名或遭遇 ID 的运行时分支。镜头、粒子、逐位公式调查和 HD-2D 不进入本批主线。

## 内容执行与应用接线

`content-batch-route.mjs` 复用 `GameEntryLoader` 准备及发布开始/读档候选，来源新游戏保留原 fade 和私有 launch。批次运行中的战斗使用 `GameBattleHandoff` 的 prepared 模式，先准备再发布，返场继续沿原 lease 一次提交角色、消耗和奖励。玩家战斗输入通过准确 owner 的 `GameCommands`；旧 owner 和重复终局操作不能转向新会话。

内容摘要、来源及清单输入继续校验。运行器不插入未声明菜单 mutation，不编辑 HP/剧情来完成路线。当前清单的稳定出口检查菜单资格和保存/恢复，恢复后的新输入程序尚待后续合同。合成内容批次和真实来源批次分别记录，自动运行器的成功不替代浏览器或原版验收。

## 普通敌人目标合同

`battle-ai-targets.ts` 提供共同能力判断与无持久状态的目标决策，编译器和运行时复用相同准入。原 AI 保持行动抽样、目标抽样及后续行动抽样的顺序；目标提供器不持有第二份名单、队列、时钟或随机流。

| 普通范围 | 初始目标 |
| --- | --- |
| 1 / 2 | 当前敌方原始名单的随机一个 / 一组 |
| 4 / 8 | 当前玩家原始名单；4 固定为一组，8 按原始人数确定单体或一组 |
| 5 | 当前行动者 |
| 9 | 当前玩家后接当前敌人，按原始名单确定单体、一组或全体 |
| 3 / 6 / 7 / 14 / 20 / 21 | 合格普通玩家中的一个；菜单默认群体不改变该选择 |

当前准入只覆盖普通存活目标及已支持编队。初始原始名单可包含尚未移除的倒地成员，效果执行仍按当前资格过滤。群体在实际执行时重新取得当前集合；单体保留实例身份，已退休实例不凭相同槽位重定向。反击仍沿准确攻击者和范围 3/7 的独立合同。

费用、所有目标效果、反应、队列与 AI 参数继续由原事务发布；后续目标失败不会留下前一目标效果或已扣费用。帧失败保留原随机状态，重试和帧切分重放保持一致。玩家均匀选择仍是明确 Web 开发规则；原生权重、特殊倒地追加、空候选原生回退与混乱等未恢复机制保持独立缺口。
