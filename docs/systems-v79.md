# v79 骨架连续游玩与内容版本

本轮继续收束公共游戏骨架。入口、探索/事件、战斗往返、队伍/经济/成长、保存恢复与批量内容仍使用既有公共 owner，不为演示或历史内容建立另一套游戏状态。

批量填充会不断改变内容摘要。本轮接通完整内容闭包的保留和旧进度续行：公共包及来源地点发布前后保留 JSON、PNG 和 FLAC；恢复按保存中的原身份选择可信版本，后续切图、事件、入战和媒体始终使用该版本。重新开始仍使用当前内容。正文、原哈希及保存格式不改写，未知或歧义版本明确拒绝。

实际 app 与公共加载器均已接线。候选会话的内容上下文随单一 Flow owner 生效；失败、取消和迟到媒体不会切换当前游戏。图片按 repository 分开缓存，历史图声先核验字节，再交给表现宿主。详见 [内容版本与旧进度](content-versions.md)。

骨架通过后，工作单位继续是一组相连地图、事件与敌队。整批工作单按公共系统汇总缺口；需要新增能力时恢复完整生命周期，同类参数由数据填充。零散 NPC、镜头、特殊技能和 HD-2D 不扩大当前骨架前置清单。
