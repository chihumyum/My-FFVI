# 批量服务与柜台交互

本轮沿用已收口的游戏骨架，选取南费加罗八个商户、六张店铺图的完整服务批次。所有店铺使用同一 Field、事件任务、Shop、GameCommands、GameState 和保存接口；地图编号、位置、商品和原始事件程序仅作为内容参数。没有按地图名称增加运行时分支。

## 来源与 Web 声明

六张图为40、59、62、221、240、243，包含十二个来源 Relay。普通商户使用原商品组5、3、4、6；四个事件商户保留完整原程序，正常领队选择66、64、65、67，来源角色5的分支选择91、89、90、92。正式初始化仍使用来源三人及3000 Gil；角色5的受控分支不算实际入队或故事到达。

v5 来源配方继承完整区域、共用战斗目录和 NPC 数据合同，另显式声明服务地图。每个派生地图绑定未派生的来源摘要、来源集、原地图引用、MapRange、循环轴、原对象和原诊断。独立检查器从完整原地图和当前来源语料重新派生宿主，核对宿主与收据，并比较原正文不变。旧配方不能暗中携带服务授权，没有被动效果的地图不能附空效果宿主。

范围仍是南费加罗全部56张来源图、135个 PointIn 和所有原依赖。两个来源地图组件间的剧情连接与世界时期保持未知。六个可选入口是明确的 Web 开发放置；声明路线通过不证明完整区域或正式主线可玩。

## 公共交互

Relay 编译保留原像素矩形、十进制来源对象身份、编辑器身份和指针。它没有一个可被猜测的“目标商户 ID”。交互只读取当前 Field 已注册的对象顺序，以及现有玩家/NPC 的原生位置；没有另建演员或交互注册 owner。

显式 Web 宿主的适用范围为步行、静止、同层和已知 Wait 目标。当前注册的 Relay 参与搜索范围投影；目标按既有注册顺序选择，同坐标目标优先。普通脚本、接话方向、载具限制、交互接管和转身仍由原系统处理。无宿主时保持旧行为；范围外的移动观察器和未知能力继续拒绝。

`FieldGame.interactionTarget(direction)` 提供只读目标投影，确认与批次面向输入共用同一判定。预览不转身、不打开服务、不启动任务。地图40的原事件 NPC 挡住正面通道，实际输入沿原侧面 Relay 到达柜台；固定路线保留来源初始化，不删除障碍或修改剧情旗标。

交易保留来源产品行和价格，成功消费一次共享 Gil/库存。事件商店停在原任务的 SysCall，关闭请求绑定捕获的访问 ID，随后执行原结束消息和 Exit。保存不把活动商店或粒子状态伪装成稳定状态；关闭后仍由原稳定检查点和入口装载器恢复，并拒绝旧会话的命令。

## 被动显示效果后置

地图59和240各有一个匿名来源效果对象，原引用、完整十九条属性及效果定义保留。只有严格符合匿名、无脚本/动作/链接/碰撞、非建筑/屏幕/鸟瞰的来源对象才可声明后置粒子显示和效果小地图。未知属性、物理对象或其他效果继续保留门禁。

该声明不分配效果、粒子、随机流或小地图状态，也不新增保存格式。匿名 EntityId 0 不是效果演员选择器。两条匹配的来源显示诊断只在声明 Web 地图的运行准入中投影，原诊断数组不删除；原版效果和真实浏览器的画面验收继续独立。
