# 共用字段 UI 与地点状态

本族覆盖完整来源的 4 个入口：`ShowMapTitle`、`UI非表示`、`マップUI全て表示`、`ミニマップ表示`。同一编译和运行时消费全部原参数，不按地图名、标题字符串或开场位置分支。完整源集合中的 79 处调用、73 个完整程序体的 7,106 条指令、51 个地图依赖闭包和 1,061 个物理资源由私有来源报告保留；这些数量是结构范围，不能写成剧情已执行。

`ShowMapTitle` 解析实际同源 `system_zhc` 的区域名和地点名。空 ID 保留为空；缺失本地化、未知控制符、额外参数和非 MainCore 形式继续阻塞。原生 MapTitle 选择合成消息，进入 Show 并从零计时；两秒时其自身 Update 关闭，解释器还另行登记两秒的 Integrator 关闭回调。Web 使用现有 Field/Session 的逻辑毫秒时钟，保留旧回调对后来标题的关闭作用。暂停和准备期间仍服从现有 Flow；战斗沿用 Session 已有的十毫秒步长推进相同标题 owner。这里不宣称 Unity 浮点累加或窗口动画的逐帧一致性。

解释器还把原始区域/地点 ID 写入 UserData 的持久 `CurrentArea` 和 `CurrentLocation`。Web 对应值只由 `GameState` 持有，通过其现有同步事务和地图草稿发布。失败、取消和过期候选不能泄漏地点变更。第一次实际写入才新增 `sourceLocation` 并使用 owned v16；未调用标题的旧状态不补空值。Field 保存的是临时 UI 状态，不能成为第二份地点记录。

`UI非表示` 的来源实际调用 MainGame 的状态 12（Event），没有直接调用可见性 setter。`ミニマップ表示` 先切到状态 11（Gimmick），再调用实际地图访问器的 `ShowOnlyNavi`。11 不是 Field。`マップUI全て表示` 调用 `ShowAllMapUI`，不改变 MainGame 状态。Web 保留这两项独立事实：事件状态隐藏并禁用地图入口；navi 请求能在事件进行时显示现有迷你地图，操作总览仍使用原输入准入；明确 ShowAll 恢复地图入口但保留原状态。它不改变移动或永久屏蔽暂停键，也不猜测未恢复的原生状态退出。

原生 `MapUIManager.ShowView` 使用 `viewTypeActiveTable` 控制 other、overlay、timer 三组，地图访问器还绑定真实玩家、交通与世界地图谓词。这次有界证据没有恢复该表初始化，故 Web 投影是明确的平台表现合同，不能充当原生可见性表、导航组件或布局的一致性证明。来源未知仍独立保留。

UI 逻辑由 Field 持有，DOM 只读当前已发布 Field 的快照，不提供 Ready 标志、第二个时钟或保存状态。地图候选继承 UI 状态，在原草稿中运行初始化并参与原有过期检查，成功后才成为当前 Field。退休和丢弃的 Field 不能再修改 UI 或持久地点。`field-runtime-ports` 是唯一转发分类：运行时策略共享，UI 种子和地点端口由原地图与持久状态 owner 提供。

活动标题及未执行关闭回调禁止稳定保存。已有稳定 UI 使用 `idle-field-v18` / `event-field-v9`，恢复检查当前显式运行时策略和同源身份，存档不能授予能力。未曾执行这些入口的旧字段继续保留其原保存格式；使运行时可用不会制造一份空 UI 状态。

验证分别记录整源静态差分、合成机制、实际 Session/Flow/原草稿/战斗往返/Storage、受控 DOM 和实际 app 的受控宿主回归。它们不替代整条原剧情批次贯通、浏览器或原版动态一致性验收。私有 native 证据共核对 16 个自身范围 / 3,568 B；新补的 8 个 Ghidra 体仅 1,920 B，两处持久 setter 的 96 B 只读 PE。所有三个输入指纹、完整 alias 和自身边界均重查；反编译尾随模板代码没有扩大证据授权。
