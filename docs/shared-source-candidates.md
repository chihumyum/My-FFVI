# Shared pure source candidates

`node scripts/compile-source-candidates.mjs --output build/source-candidate` compiles the full strict source set and the explicitly declared Web framework once, then links prerequisites once. It writes a private object closure, the full original prerequisite input lock and a receipt. It does not publish, claim original-game parity, or admit a story route.

All four complete-family observers accept `--candidate-dir build/source-candidate`: `check-source-map-animation-programs.mjs`, `check-source-play-animation-programs.mjs`, `check-source-flat-npc-programs.mjs`, and `check-source-birdview-field-effect-programs.mjs`. Their old producer commands and default directories remain supported through the same implementation. Each observer keeps its independent source nomination, full installed namespace/dependencies, original initializer attempts, native evidence and unknown cases. The observer receipts identify the exact shared candidate bytes. Construction, mechanic execution and story reachability remain separate measures.

Reuse does not weaken provenance. The producer and each observer use the existing complete runtime digest, compiled modules, tools, app and tests. Each observer validates the full prerequisite lock, receipt/lock byte hashes and every candidate object at the start and end. Candidate object URLs are unique and directory-bound; returned parsed objects are detached. An old runtime receipt is rejected rather than re-signed. No public collection or timestamp is a cache authority.

The reader also follows every map reference in both complete world catalogs. Source and framework map IDs, producer/link denominators, manifest membership, content hashes and actual map/source identities must agree, including maps outside the selected family. A missing unrelated map cannot silently shrink the candidate closure.

Five inventory producers can consume this same candidate with optional `--candidate-dir`: `inspect-source-script-random.mjs`, `inspect-source-message-fees.mjs`, `inspect-source-global-npc-area.mjs`, `inspect-source-event-activation.mjs`, and `compile-source-assigned-routes.mjs`. Without that option they retain their full pure compile. The shared path uses linked world/entry URLs and hashes, preserves every object URL, and records the candidate receipt and complete input lock. Their own full raw corpus, source nomination, dependency graph, native evidence and family-specific audits still run. The fee producer still requires the exact whole-common addition and unchanged original owned initialization. Every producer validates the common candidate again before issuing its final inventory. Identical locked logical/package aliases may share the same detached value, as they do in the pure linker; all physical object files remain checked.

`source-framework-map-overlay.mjs` composes a sealed strict map, its same-candidate complete framework variant and the initialized recipe variant. It preserves the complete framework map, effects catalog and source-family sidecars, including `frameworkNpcFlat`. Only the recipe's declared activity, services, walking and presentation fields are overlaid. Original scripts, script locals, transition/system/puppet metadata and all other source fields must remain exact. Source policy markers come from the framework variant, not a recipe guess. The matching world composition preserves initialized URLs/map membership and seals the new exact map hashes. This corrects observer omissions; it does not relax a game admission guard or create another runtime owner.

Create a new candidate after any runtime/tool/test change. Do not edit a receipt to match a newer runtime. Parent publication still uses the single existing public package pipeline; these tools only prepare and inspect private immutable candidates.
