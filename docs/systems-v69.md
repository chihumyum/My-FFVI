# v69 可操作的游戏系统骨架

用户再次明确要求系统优先。本批停止扩大地图和孤立来源指令，将已接通的游戏系统集中到一个页面可操作的演示入口，并修复共同切图生命周期。HD-2D、精细演出和完整原版对照继续后置。

## 交付与操作

打开 `/game/?package=systems-playground`，或在普通标题页选择“游戏系统演示”。进入后向上移动，确认补给对白并进行第一场战斗；胜利返回后，可按 Esc 查看队伍、换装、调整前后排、使用道具、保存及读取。随后向右经过入口，在第二阶段向上继续第二场战斗。

演示使用原纳尔谢几何和原始普通敌队数据，入口队伍与初始库存保持原开发基线。两个阶段、触发器、对白与补给是明确的作者内容；它们用于验证系统接缝，不代表原剧情或地图可达性。游戏状态只通过移动、确认、公共菜单命令及战斗命令改变，不设置测试 HP、瞬移或补齐未知剧情旗标。

作者阶段的地图物品资格明确继承借用几何的来源地图3规则，并形成独立战斗目录摘要与来源记录。原普通敌队目录不改；检查器不能伪造地图ID、补默认资格或直接修改内容以通过入战。

## 系统分工

| 系统 | 唯一负责的状态或边界 |
| --- | --- |
| `GameFlow` | 标题、暂停、宿主输入与时间门控、操作票据 |
| `GameSession` | 探索到战斗的借用、固定入场重试、奖励返场与检查点组合 |
| `WorldSession` / `FieldGame` | 地图候选、碰撞、触发器、事件任务与剧情变量 |
| `GameState` | 名册、编队、库存、装备、能力、成长与已结算记录 |
| `BattleGame` | ATB、行动、目标、AI、效果与本场结果；返场前保持独立副本 |
| `GameContentRepository` | 可信内容引用、摘要、依赖装载与恢复所需的内容 |
| Entry / Map / Battle 协调器 | 私有准备、媒体就绪、一次发布、取消与过期拒绝 |
| `GameCommands` / `CheckpointStorage` | 对当前会话授权用户操作；原子保存当前及上一份进度 |

页面和检查器使用相同接口。新增内容只能提供数据和配方，不增加按地图名、敌队 ID 或剧情场景分派的运行规则。共同骨架按连续流程验收；特殊角色、状态、技能、交通与完整来源剧情继续按自身依赖准入。

## 本批共同修复

`GameMapLoader` 注册原 Flow 票据的失效回调，在最终地图验证期间撤销私有世界候选。返回标题或替换会话后，旧地图和媒体不得发布；一旦 owned 发布开始，取消会被拒绝并保留原票据。成功提交后还须核对当前会话与实际地图，不能将发布后的异常解释成可重试准备失败。

保存命名空间由宿主选择的内容包 ID 与 profile 绑定。各内容包分别保留当前及上一份进度；普通来源和 framework 的旧键与字节不变。保存格式仍为 `web-game-save-v1` / `game-checkpoint-v5`，存档不能选择内容 URL、摘要或存储键。未命名的旧内容包进度不自动复制到新包槽。

## 构建与验收

`npm run playground:build` 从既有来源产物构建演示内容；作者配方在 `content-batches/systems-playground.recipe.json`。原始资源、生成内容与回执仍保留在忽略的 `build/` 中。

`npm run playground:check` 在实际演示包上连续运行：标题、新会话、触发器、补给、准备入战、行动、奖励、返场、菜单、保存恢复、后续移动、切图和第二战。`npm run framework:verify` 将该流程纳入共同系统检查。入口页面另由现有受控 DOM 检查验证。

本批 TypeScript2785/2785、Python工具43/43及绑定检查16/16通过。统一框架检查44组，其中43组受控系统合同通过，另1组来源路线仍未完成；页面受控DOM38/38、实际演示内容包连续检查12/12通过。两次存取后继续移动与第二战、一次奖励、补给不重复、旧命令拒绝均已执行；既有15个内容包文件逐字节不变。

具体执行结果保存在 `build/reports/v69-validation-summary.json`。受控运行与 DOM 检查不表示本批执行了真实浏览器或原版；完整 Web 迁移目标保持 active。

## 接续顺序

先以这个入口检查完整用户操作与系统稳定性，再统一导入地图、事件、敌队、物品和角色的数据依赖。批次遇到实际共同机制缺口时，按影响范围补一套公共能力；不以逐场景调演出或孤立源码方法研究作为主要进度。全游戏主线、支线与兼容性验收通过后，才恢复 HD-2D 工作。
