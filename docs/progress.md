## 本轮修正的来源问题

Unity signed 64-bit path ID 以字符串传递；引用包含序列化文件身份。Timeline 无限外推保留为带标签的 Unity 数值，不伪造为有限时间。

Map_20010/map019 的图集导出使用 Unity 存储行序（`flip=False`）。UnityPy 默认图像属性会翻转该图集，改变图块地址，导致地图拼接错乱。浏览器检查确认修正后道路、房屋与山壁连贯。此观察仅支持当前图集静态投影，不替代原版截图对照，也不推广为所有类型纹理的统一规则。纹理按内容摘要命名，避免替换同名图片后的旧缓存干扰检查。
