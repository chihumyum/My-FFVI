# 系统集成 v33

本批继续搭建共用系统：地图局部原生 NPC、来源 SetPos、效果板生命周期和普通身体/头部图层合成。真实新游戏仍在 `sc_e_0001` 指令19请求 map609→map3 时停止；完整开场和全游戏迁移尚未完成。没有新增剧情可达性或开始 HD-2D。

## 单一演员所有权

kind6/17 的静止 NPC 使用 mapobject 身份、自己的动画媒体和来源初始朝向，加入已有 `FieldGame.actors`。它们不冒用队伍 field-character ID，也不复制一套供脚本操作的演员。默认组先私下准备，事件组在所有媒体、身份和控制器检查通过后整体登记；来源更新属性2/10决定字幕期间是否更新。来源 `turn_around` 引起的第二次 Look 保留，可切换到同方向停止动画的 next 键。

匿名 NPC 的 `entity_id=0` 只表示没有可选择的脚本编号。内部身份由来源组及对象 pointer 构成，不转换成 NaN，也不占用镜头 selector0。集成审查复现了默认匿名角色被拒绝、事件匿名角色先发布后无法读取上下文的问题；两条路径与坏 selector 的零发布回归现已纳入检查。负选择器不作为 NPC 偷用队伍/常驻角色分派。

MapManager 越界停放点由真实场景根与原生构造共同绑定为(30000,30000)，与常驻角色初始停放位置分开。切图只把常驻角色交给目标地图，局部 NPC 随旧地图退休；过期检查仍包含全部 NPC 的位置、动画、媒体及显隐状态，不能忽略即将退休的角色变化。详见 [原生 NPC](field-native-npc.md)。

来源 SetPos mode0 在地图原点减法后处理负轴，保留当前格子或按来源层1..3重绑材质；layer0保留原层。坐标、层、透明纹理和 CueAnimation 在一个临时候选上准备，再提交到已有演员。缺媒体、未绑定材质、活动移动、骑乘或变化的所有者均拒绝，不部分移动或擅自 Show。真实后继片段的定位指令用于独立机制检查，未因此开放整个片段。

## 效果板与图层合成

kind11 已识别为 `FieldEffectBoardEntity`，其板、共享粒子播放器、引用计数和纹理各自有明确角色。默认组按来源顺序创建，共享实例释放、播放、停止、组激活、42更新掩码和独立的 activeSelf/fadeAlpha 已建立事务接口；特效不进入角色集合或角色隐藏集合。事件组的预创建顺序、真实粒子随机/Noise/预热、材质深度、地图分配与回收事务、稳定粒子保存仍是独立缺口。WorldSession 在准备前阻止带效果的进出图，避免候选地图提前向外部宿主发布资源。

真实 map3 的15个默认效果板引用5个效果资产。导出仅跟随实际 `Prefabs/EffectPrefab` 根；同包另一个原始 prefab 不重复计作运行时粒子。Unity path ID 始终保留十进制字符串。没有用循环贴图、静态板或假粒子代替这些提供器。详见 [效果板](field-effects.md)。

普通合成恢复了图块两遍 alpha 测试、角色身体/头部 UV 分界、来源深度与材质覆盖后的渲染顺序。透明混合的 alpha 算术不同于 Canvas source-over；集成审查发现并修复了最终画回 Canvas 时的二次混合。CPU framebuffer 从已准备背景像素开始，完成所有准入 pass 后一次发布。

Upper/Ceil 描述符区分不存在、空层与非空未实现。普通身体/头部路径支持前两者；非空渲染目标的创建、相机和采样没有被 shader 公式测试代替。map3 继续精确阻塞。角色阴影沿用既有开发偏差：保留逻辑 shadowVisible，渲染器报告缺失，界面列出限制；骑乘、半透明状态和其他未恢复提供器仍拒绝。不能将普通身体/头部合成报告为完整 GPU 或视觉一致性。详见 [普通原生合成](field-native-composition.md)。

旧纳尔谢开发检查点此前就省略环境粒子。本批将这些来源身份显式移至 `developmentOmissions`，后续实体组的 blocker 仍保留；真实世界包不执行该变换。旧检查点可玩回归与来源新游戏准入分别验收。
