# v88 批次事件的共用演员控制

本次工作由南费加罗完整区域的依赖工作单选出：56张地图、135个来源入口及全部475条原诊断继续保留。共用演员控制接入21处相对定位和18处即时显示；数量来自实际根依赖闭包，附着但未被根引用的脚本副本不计入。基础骨架保持原来的六组、七条代表性流程，不增加另一套演员或游戏状态所有者。

## 命令与提交

`FieldGame.prepareActorControl` 将当前任务的准确演员、来源参考 selector 和宿主准备连接起来。定位使用现有 `prepareNativeFieldActorProjection`，显隐使用既有 native actor、camera 或 effect owner；来源宿主缺失不能退回旧开发演员。操作先完成依赖与媒体准备，再一次发布到原实例。参考演员的位置或实例改变、selector 解析改变、媒体失败均拒绝候选。

SetPos mode0保留原四字段合同。mode1额外保存 `mode:1` 和 `referenceEntityId`，由已有 `resolveFieldPuppetActor` 解析到准确实例。参考世界位置先转为地图局部格子，再以逐步float32算术加来源偏移，不重复减地图原点，也不套用mode0的负数保轴规则。最终Z取目标演员自身的原Z或明确新层，动画、层材质和位置共同准备。定位保留隐藏、方向、实例和骑乘身份，不调用Show或Init。

来源语义依据为既有 `Puppet.SetPos 0x2c6a30` 的mode1分支及 `MoveEntityLayerWithWorldPosition 0x2c26f0`。参考实体为空的路径拒绝；没有以空操作或默认玩家替代。新功能没有新增原生导出或自主NPC控制器。

即时Show/Hide仅接收type2、完整八槽且全部reserved为零、duration和delay均为零的来源形状。显隐继续检验子对象传播，效果板和camera保持各自现有状态所有者。批次内四处Hide实际为duration0、delay0.1，仍阻塞；Orient、Route、AssignMoveRoute、Mob恢复和RelayInteraction不因本次接线获得执行能力。

完整decoder拒绝显式错误指令类型或失败的来源参数后回落到旧作者规则；完全缺type的旧作者形状和已编译旧Op仍保留。即时Hide继续参与玩家puppet的跳过分配规则，实际事件回归验证后续NPC仍可使用同一槽位。

## 内容与验收边界

新 `actorControl` 准入需求保留运行宿主依赖：未知是conditional，明确缺失是blocked。解码成功不关闭这些依赖。批次工作单归入地图/事件组，内容依然由一个候选、一次公共发布生产；旧版本及原存档依赖保留，不隐式升级来源内容。

独立连续测试通过公共Flow、菜单、Storage和EntryLoader验证显隐、相对定位、事件续行、稳定保存恢复、失败切图保留有效owner与重试后退休。来源检查器使用完整批次原参数和来源定位验证解码、准备及当前发布IR，原脚本通关与受控机制探针分别记录。

执行 `node scripts/check-source-actor-control.mjs --require-current-ir` 可检查当前发布内容；完整验证还包括 `npm run check`、Python适配器测试、单候选生产、原有骨架和三个来源声明路线。最终证据保存在本地 `build/reports/v88-validation-summary.json`。实际浏览器、原版动态对照和完整剧情均独立验收；完整Web迁移goal继续active，HD-2D后置。

本次实际发布10个入口包，4548个地图引用与完整JSON/媒体归档通过。内核3325项、Python43+16项、骨架六组/七个检查器/112个连续用例、三个来源声明路线/7项检查及演员来源7项检查全部通过。当前IR与全部60个去重来源site的重新解码一致，其中39个新命令保留准确宿主要求；102条演员控制需求包含旧即时Hide，不能把这些需求删除后声称剧情已准入。完整区域仍有436条静态诊断、441条提供器要求和399份评估，引用闭包不完整。
