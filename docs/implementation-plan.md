# 实施计划

当前唯一主线是原版 Web 迁移。先交付 [可操作系统骨架](game-skeleton.md)，再以成组内容补充公共能力。模块、所有权、并行分工与退出条件见 [系统推进计划](systems-roadmap.md)；下方原始阶段描述不是当前工作队列。

本轮收拢默认系统入口、代表性连续流程门禁和批量路线数据接口。既有探索/事件、战斗往返、队伍/装备/商店/成长、存读档均复用同一公共运行时。原版开场的单条镜头或特殊能力不阻塞该里程碑，也不能被跳过后宣称剧情已迁移。

骨架退出条件是：默认入口可操作；公共 API 贯通事件、战斗、返场、菜单、切图与恢复后续行；失败/取消不替换有效 owner；重复操作不重复扣量或发奖；批次接口能报告依赖缺口。准入范围绑定当前构建和具体内容，浏览器、原版对照及全游戏门禁分别留证。

骨架通过后的工作单位是一组相连地图、事件与敌队。批次规划汇总完整依赖，缺口按共用系统归并；内容以数据接入，不增加地图名或敌队 ID 分支。NPC、交通或特殊战斗只在实际批次需要时作为整块系统推进，不能恢复逐场景研究主线。

用户已将原版对照后置，当前以可操作流程和来源数据检查推进。完整 Web goal 保持 active；HD-2D 调查、风格和制作均在完整迁移放行后开展。各 `systems-v*.md` 保留历史交付证据，历史数量不代表本轮验证结果。

## 阶段 0 建立可追溯工程

交付：仓库、架构与工作规则、来源适配器、稳定对象 ID、真实源清单、语义查询与资源匹配、严格验收框架、检查工作台。验证纳尔谢的源表关联与二维图层读取，提取歌剧轨道/镜头/绑定，显示所有尚未恢复的行为。

阶段 0 已建立；阶段 1/2 已推进到独立 Web 纳尔谢片段，支持移动、碰撞、守卫演出与对白，现已接通首战、结算与返回地图。当前实现及下一任务见 [Web 场景运行时](web-field.md)。全游戏可玩性与等价演出仍未完成。原始文件未进入 Git。

## 阶段 1 确认两个样本与原版观测

纳尔谢：从已关联的 20 个主城地图记录中确认开场所用地图/层/剧情状态；建立一小段相连地图、一次对话、一次战斗的范围。歌剧：根据源时间线和原版观测选定可独立采样的短镜头，并列出外部引用闭包。

准备原版运行环境，采集独立存档、输入、画面、时间及状态检查点。确定 WorldState 和状态 flag 的源映射。语义来源链成功关联不等于剧情时间已恢复。

退出条件：样本范围、进入/退出状态、证据位置、实际待实现能力清单均明确。

## 阶段 2 最小游戏内核

实现已验证子集的时间与任务生命周期、地图移动/碰撞/入口、对话、剧情 flags；针对指令参数和系统调用建立类型化编译。逐步加入样本战斗、随机输入记录与版本化存档。按当前优先级先在显式开发 profile 内完成可玩流程，临时规则逐项留证；一致性对照后置，未验证的能力不能关闭正式门禁。

退出条件：纳尔谢样本可以在 Web 玩到，并通过行为、存读档、离开重返和暂停恢复对照。未知指令仍明确阻塞。

## 阶段 3 现有歌剧 Web 迁移

导入 Mesh/Sprite/Material、对象层级、相机和曲线；把源 Timeline 的受支持轨道编译为 CutsceneIR。实现音频同步、轨道绑定、启用状态、跳过/恢复契约，以及片段实际使用的后处理。由实测决定渲染后端；Babylon.js 为当前候选，不让内核依赖它。

退出条件：短片段的固定时间点和播放行为对照通过。序列化相机数量不代表同时启用相机数量。

## 阶段 4 成批 Web 迁移

以区域地图群和剧情边界生成依赖闭包、入口快照、验收场景和退出状态。先处理已验证能力覆盖的批次，再逐项增加世界地图、飞空艇、多队伍、特殊战斗、演出、菜单和支线。推进单位是能力与语义覆盖，不以地图数量代替正确性。世界知识与资源登记服务于原版地图/剧情状态选择，不在本阶段创作重制资产。

退出条件：覆盖清单逐项闭合；全主线从开场到结局、可达支线、地图/战斗/菜单系统和保存恢复均有独立原版证据。未覆盖内容不得静默移出范围。

## 阶段 5 Web 迁移放行

固定源版本和候选构建。通过全流程检查点、跨世界阶段回归、存档兼容、错误恢复、目标浏览器实机与性能预算。记录每项已覆盖内容及例外；未获明确范围变更的缺口继续阻塞。纳尔谢和歌剧样本通过不等于此阶段通过。

退出条件：迁移验收清单没有未知或失败项，证据绑定当前构建。此后才进入 HD-2D 调查。

## 阶段 6 HD-2D 调查与独立重制工作流

前置：阶段 5 放行。先调查已迁移歌剧的可推广范围，测量并审核风格规则，再落实地点/状态语义标注、资产请求与候选审核、版本化风格、装配接口、场景配方及空间检查。纳尔谢先使用受控的建筑/雪地规则。

退出条件：同一纳尔谢逻辑内容切换参考/重制表现，逻辑验收不变；三张同类场景和留出地图验证批处理与资源复用；共享资产升级影响报告完整。

## 阶段 7 用户扩展

新剧情、资源与规则采用单独 profile 和显式 patch；维护基线、修改意图、存档迁移和原版回归。原版还原的验收与新增内容的设计验收分别记录。

## 初始研究队列（历史）

最初的纳尔谢地图/实体组、事件指令和歌剧 Timeline 调查保留在相应 dossier 与批次文档中；其中未完成的依赖继续可见，但不覆盖上方系统优先的执行顺序。陌生来源样本当前用于验证共享机制，不能因此提前恢复区域填充或 HD-2D 工作。

每项交付证据、适用范围、未知项、测试与后续工作。未获得原版运行证据前，行为 lane 保持 unknown。
