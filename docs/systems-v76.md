# v76 整体骨架入口与门禁

默认 `/game/` 先展示系统版，通过实际来源初始化与作者训练设施操作战斗、商店、装备、编队、魔法、魔石和存读档。此前默认原迁移样本仍可能在未恢复的原剧情处停止；现在标题提供明确的系统版、世界旅行和原迁移样本切换。显式 query 保留已有行为，默认系统版与显式系统包共用同一独立保存槽。

所有运行仍使用原 Repository、EntryLoader、Flow、Session、Commands、地图装载和 prepared 战斗交接；没有新增演示专用持久 owner。菜单、战斗和保存继续使用相同角色、库存、成长、剧情与随机状态。

## 本轮结果

- `npm run check`：3,039 项 TypeScript 测试与注册表校验通过；项目 Python 环境下 43 项测试通过。
- `npm run skeleton:check`：六组公共合同、七条新鲜检查全部通过，共107个场景；默认 actual app、事件/两战/返场、持有经济成长、地图旅行和存档续行使用同一运行时摘要。
- `npm run npc-routes:plan`：649 条地图逐包绑定；58 条有路线声明，171 个包内声明均解析，未发现非法结构或缺失绑定。计数是包内声明，不能当作独立源资产或可玩地图数量。完整原字段、来源、10种指令和所需能力进入公共数据接口；运行 consumer 尚未实现。

准确构建、逐项结果和日志保留于本地 `build/reports/v76-validation-summary.json`、`game-skeleton-check.json` 和 `game-skeleton/`。门禁合同见 [可执行骨架](game-skeleton.md)。原始资源及生成产物保持 ignored。

## 后续范围

骨架通过允许继续选择声明内容批次，具体批次仍须自己的完整依赖与连续路线准入。NPC 自主控制、交通和特殊战斗按选定批次的共同需求整块推进；单条镜头、逐位数值或特殊技能不扩大骨架前置清单。当前次序见 [系统推进计划](systems-roadmap.md)，历史重复队列已收拢。

UI 证据是实际 app 的受控 DOM/媒体/绘制替身；没有新增浏览器、原版表现或来源主线验收。完整 Web 迁移 goal 保持 active，HD-2D 后置。
