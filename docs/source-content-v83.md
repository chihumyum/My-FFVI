# v83 整批来源内容生产

骨架收口后，工作单位改为成组来源内容与它们实际需要的公共能力。本轮统一选择费加罗22/23和南费加罗室内228、229、230、231、233、234、235、236，两批使用同一来源初始化、同一生产器和一次公共集合发布。八张室内地图的静态身份、原出口、入口和未闭合条件见 [地点 dossier](../targets/south-figaro.md)。

## 公共接口

`source-batches.selection.json` 严格绑定原配方字节；全量预检包/manifest 唯一性和命名所有权后，现有候选管线并行编译所选包。正文、引用、manifest、报告冲突均拒绝。发布前复核选择、配方、来源、媒体和本次完整运行时，任一变化不替换旧集合。

同集合的选择回执绑定统一工作单。工作单按既有六组系统及未分类组归并全部诊断/provider 记录，保留每批原内容摘要、来源位置、索引及条件性。它负责生产实施，不改变游戏状态、能力或准入。

实际 app 对新的初始化来源包提供通用地点入口与提示，系统训练场保留自己的玩法说明。新的地点只需配方与引用包，不添加包名或地图名的运行分支；仍由原 GameEntryLoader、GameSession、WorldSession、GameCommands 和 CheckpointStorage 运行。

## 依赖正确性

来源步行遇敌配置进入世界编译与依赖图。保留整行 map/set 原字段和每个敌队/率值；原始率不转换为运行时权重。缺表、坏值、额外槽位和未编译的区域网格明确留证。南费加罗234的 set154不再因没有显式 Encount 指令而漏掉375、374、126敌队依赖。

这项数据合同没有实现原版遇敌调度，也不改变现有开发步行策略。两批的外部地图、未走分支、其余路线和完整剧情仍按各自依赖门禁记录。

## 验证

`npm run source-batches:check` 从实际公共选择回执、refs、manifest 和地图重新规划，再执行声明路线；所有来源正文完整对照，媒体完成由受控 host 提供。南费加罗当前声明路线为228→229、菜单设置、保存恢复和恢复后输入，其他六图的未覆盖路线保持诊断。该结果与全批准入、浏览器实玩、原版对照及全游戏验收分开。

本轮实际公共候选一次发布九个包，全部3899个目录地图引用核对通过，完整 JSON/媒体归档完成。两批声明路线及完整来源正文对照共五项检查通过；骨架七个检查器的112个连续用例通过，内容版本会话回归14项通过，`npm run check` 3232项及 registry 检查通过，Python 43+16项通过。受控 host 结果不代替实际浏览器或原版执行。

全批门禁重新运行后仍按预期拒绝：费加罗保留13条诊断，南费加罗保留19条，包括外部地图、六图未覆盖路线、步行遇敌策略和126/374/375敌队缺失。完成声明路线没有移除任何来源缺口。

首次候选在发布前因新增来源表证据使物理来源清单变化而停止。新增的证据扩充协议必须从已验证的原始 map/set 行重构完整元数据，再允许从比较副本中剥离该数据字段；原正文、原配方、率值、SourceRef、普通身份、媒体和省略项门禁保持严格核验。候选报告记录扩充前后清单摘要及核验证据。此后整条公共管线通过，旧 JSON 字节与版本保留。
