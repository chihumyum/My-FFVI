# v18 并行系统集成

2026-10-11。开发目录 `narshe-playability-v18`，持有状态 `owned-game-state` v5，外层 `game-checkpoint` v2，字段/世界为 `idle-field-v2` / `idle-world-v2`。本批补普通初始化提供器、地图毒伤与 WAIT 菜单；完整系统与全游戏迁移门禁仍未通过，区域填充和 HD-2D 保持后置。

## 并行与集成

三个工作线各自拥有纯模块、来源编译、测试与说明；集成线统一修改状态所有者、格式、宿主和浏览器。原生导出串行占用，已导出资料和实现并行。交叉审查找到并修复四个集成缺陷：初始化阶段开始的移动在地图发布后被错误判为过期；伪造存档交通身份可绕过毒伤；不含步行效果能力的内容在切图后意外获得该端口；角色名称绑定误用本地化键。另修复工作台胜利后读取已销毁状态时钟的显示错误。

## 角色初始化与能力身份

普通初始化恢复六个命令槽、通用命令、按来源组顺序创建的持有能力、初始学习值、命令能力映射、职业与初装参数。HP/MP 在装备前恢复，最终上限在装备后确认；成长修正和学习仍独立准入。34 条角色记录有 18 条普通初始化可编译、16 条明确阻塞，这不是 18 个可玩角色。

正式开场三个 owner 保存 63/4/4 条能力和 63 条全局去重历史。原生全局历史包括学习值 0 的持有能力，不等于已学会清单。`mes_id_name` 用于本地化初始显示名，剧情名称另由 `character_default_name.tag_name` 绑定；仅角色 1 建立 `TINA`，31/32 没有绑定。

快照 v5 校验完整能力容器、全局历史和名称标签；未迁移的学习不能通过存档注入。来源调查需要读取更多能力行，但活动战斗仍由独立 `battleAbilityIds` 闭包准入。当前战斗从受控定义投影命令/能力，尚未动态消费全部 owned 映射；不把持有记录当作动作实现。受控洛克初始化检查装备只登记一次和失败回滚，没有向正式开场授予角色。见 [角色初始化](owned-character.md)。

## 地图移动与状态事务

玩家自由移动和脚本移动在起步时准备当前队伍副本，完成后提交毒伤，再发布目的地事件或借用战斗状态。碰撞、转向、静止帧、NPC 移动、检查点恢复不会增加毒伤。普通毒按最大 HP/32 整数截断，无最少 1 伤害、无元素修正；活人最低 1 HP，死亡成员保持 0，按来源追加濒死。音效与 shader 仍缺表现实现，不能重复驱动数值。

地图候选的库存、编队、生命周期与步行端口共享版本。候选内开始的步行可在正常发布后完成一次；其他持有状态变化使旧准备失效。这个保守并发限制是 Web 的当前边界，不冒充原版所有并发行为。

交通身份独立于骑乘画面，并进入字段/世界检查点 v2。`RideVehicleNPC(6)` 不证明 `currentTransport=6`。当前没有完整交通切换提供器，恢复必须匹配可信入口身份，不能相信存档声称的免疫交通。正式开场交通身份未知，有毒移动仍明确阻塞且菜单可解毒；工作台使用显式交通身份 1。见 [地图步行状态](field-conditions.md)。

## WAIT 菜单与保存

会话持有即时/等待偏好，传入每次创建或重试的战斗，并存入外层检查点 v2。基本指令页允许推进；技能/道具列表与目标页在 WAIT 模式发布 UI 等待，返回、切角色、重试及隐藏时立即更新。暂停、帮助、强制等待与进度许可仍独立。时速固定为 1，没有猜测原版完整速度档位。

旧格式及不合法偏好整体拒绝；原有浏览器存档不覆盖。持有能力/历史/名称随保存、恢复、入战、重试、胜利和再次恢复保持一致。活动战斗/事件保存及旧版本迁移仍未实现。见 [战斗计时](battle-timing.md)、[检查点](checkpoint-saves.md)。
