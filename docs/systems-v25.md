# 系统集成 v25

本批接通普通前后排、加速/减速和商店买卖。三条独立实现线共享既有字段、角色、库存与战斗所有者，集成线负责入口资格、事务、版本和最终验证。纳尔谢继续作回归；没有增加按地图名称分支的运行时规则，也没有启动 HD-2D。

## 前后排

`GameState.partyPlayers` 从当前编队格读取行位，入战冻结真实六槽装备。物理计算先在基础攻击值后处理攻击方后排，再在目标防御后处理目标后排；来源特殊能力与手槽武器例外分别投影。敌人的来源行位固定为前排，构造及推进前都会校验。缺少目录或玩家装备所有者时，依赖这些输入的物理行动不会入队；不将未知行位当成前排。

完整行位元数据包含 1530 个能力和 223 个装备身份，这不授予它们执行资格。18 件带后排例外的武器仍受原有装备准入限制；双持、双手、战斗换列及特殊阵型仍未迁移。三个真实来源角色的受控普通攻击在前/后排得到 31/15、40/20、42/21 伤害，使用真实持有状态和租约，结束后持有快照不变。见 [前后排](battle-row.md)。

## 加速与减速

普通 row21/type15 与 row25/type16 进入状态生命周期、冲突替换及能力编译。ATB 按来源百分比累加；蓄力使用独立倍数；毒等周期使用来源的 8/16/32 秒规则，保留已经缓存的本轮阈值。不能用同一个速度倍数替代三种算法。

Slow 的 elapsed 是独立 float32 秒数，按状态更新门控推进，普通 until2 不会因为该计数自动到期。状态移除、重新施加、死亡、战斗结束和失败帧回滚都处理对应的本地时钟。字段稳定保存不持久化这些战斗本地状态。

29 个来源速度能力候选中 24 个获得有界计划，5 个仍因其他提供器阻塞；完整能力目录现有 291/1530 个有界宿主计划，另有一个只有算术计划的记录不进入宿主。来源特殊 row95、粒子表现及原版动态一致性仍未验证。见 [速度状态](condition-speed.md)。

## 普通商店

ShopNPC 与既有静止 NPC 共用演员、朝向、碰撞和交互规则。流程是前导对白、交易窗口、结束对白，再恢复字段交互；只有窗口打开时能交易，整个过程不能移动、开背包或保存稳定检查点。字段准备阶段的资格读取候选库存，不读取另一份陈旧状态。

来源买价为基础价格加 Product.Coefficient；售卖读取来源 sell 值。买入数量同时受余额和总持有上限约束，售出只允许未装备副本，并预先限制 Gil 剩余容量。`GameState.prepareShopTrade` 在一个候选中按来源顺序更新物品/装备和金币，再一次发布；余额、装备占用、过期事务、重复提交和战斗租约都在所有者内校验。浏览器只通过当前 `GameSession` 的商店入口提交。

目录保留 92 个普通商品组、595 个商品和 273 个物品/装备身份；38 条没有 ProductGroup 的服务费用行不伪装成普通商店。71 处 action8 中 69 处消息可编，实体完整准入为 64 处；另外 2 处消息控制和 5 处 NPC 移动仍阻塞。49 处特殊脚本商店调用未开放。这些是依赖检查数量，不代表剧情已能到达这些地点。见 [商店](shops.md)。

## 交付边界

配置为 `narshe-playability-v25`，稳定格式保持 owned v6、field/world v5、session v2；旧内容哈希的存档仍明确拒绝。静态原生方法/汇编核验保留 `semanticsVerified=false`。缺失的原版动态对照按用户指示后置，完整系统和全游戏门禁仍未通过。

来源资源、原生导出、生成包和截图留在忽略的本地产物。代码、合成测试、来源核验脚本和工程文档由私有 GitHub 仓库追踪。
