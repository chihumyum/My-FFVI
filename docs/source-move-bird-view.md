# MoveBirdView common actor lifecycle

All68 original MoveBirdView operand sites use one decoder and actor implementation. The complete16 bodies/2959 instructions remain retained, including66 delegations to normal Move,2 height-only operations and2 positive interpolation durations. The full3304-script/186003-instruction denominator and its other diagnostics remain in the pure source audit. These counts are static capability evidence, not source story execution.

The original2c22b0 first clock rejects a negative r1 duration, converts r0 to float and clamps it to[-1,3], reads IEntityAccessor14 for the current entity, and stores start, target=(ratio×60)+60 and entry time. It calls the existing Puppet.Move with the same i0/i1/i2/s0 only if i1>0; otherwise it waits. Later clocks interpolate against the same time, call slot13 for this same entity and wait until both height and FieldEntity movement have completed. Height-only instructions do not interpret unused direction/speed/animation operands, including the original direction4 site. The original accessor2de9b0/2df510 returns0/discards a write when its controller or actual BirdViewPuppet is absent. Unknown presence cannot use that branch.

The explicit Web variant uses `web-flat-bird-view-actors-v1` on both trusted DevelopmentProfile.birdViewActors and GameSessionRuntime.birdViewActors. It creates an elevation component on an actual, already bound ordinary native Actor. Its initial0 and sprite-only projection are deliberate Web presentation choices; they do not claim a Unity BirdViewController registry or exact 3D behavior. Camera/effect/unknown actors and riding/forms remain gated. A saved value never supplies either policy, a native source binding or a missing actor.

The existing FieldGame Actor retains ground position, source layers, collision, animation and Actor.motion. Delegated movement directly uses startScriptMove, its seven source speeds and all existing loop, actual-player magnification, raycast and media gates. The existing Task.generalRegisters r0/r1/r2 hold start, target and entry time. Task.birdViewMove retains only the immutable bank identity and exact live instance references; another task cannot steal that actor's motion/height. Height updates run beside ordinary movement on the existing Field clock. A first-clock yield remains observable even for zero duration. Renderer lifts that actor's image while keeping ground sorting, logical coordinates, collision, camera and triggers unchanged.

Stable numeric poses live inside the existing native field checkpoint. Restore reconstructs actual native actors from trusted content first, validates map/content/actor identity and attaches values to those new instances. Unfinished puppet/height/movement and save barriers reject checkpointing. Map preparation failure/discard preserves the old component; publication creates fresh destination components and the old field cannot keep ticking. Prepared battle media failure and return reuse the same suspended field component, while rewards and owned resources keep their original transaction.

Validation covers typed source operands, float clamping, known-absent versus unknown accessors, real PuppetCore/Main scheduling, motion/height completion, pause, ownership conflicts, prepublication media failure, missing content/runtime authority, Storage, actor replacement, map failure/discard/retry/retirement and prepared battle return. The source audit and controlled production Renderer checks remain separate from browser pixels, native dynamic parity and full campaign acceptance. No source ID, script name or PC selects behavior.
