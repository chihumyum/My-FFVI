## 已收拢的两块闭环

v72 已将声明交易和离店续行接到公共 runner，贯通“购买/出售 → 使用或装备 → 两战 → 切图 → 保存恢复”。未声明交易继续拒绝，错误窗口和恢复前的旧操作不能执行；验证范围是完整的受控系统链。

魔石系统已接入取得、装备/转移/卸下、战后部分熟练度、学会后的字段与战斗使用、逐级奖励以及保存恢复。全局持有来自来源初始化域；旧开发入口没有该域时不能取得。菜单卸下、库存移除和离队的原生关联清除分别记录，不能混用。

召唤等特殊能力仍是独立内容缺口；只在选定内容批次实际需要时作为公共系统增量推进，不继续扩大骨架前置清单。

`GameState` 唯一持有魔石与角色进度；战斗租约冻结实际装备，结算带实际 MagicPoint。owned v14 保存有序成长依据，不能用当前装备回算过去等级。来源未知的召唤效果和禁用角色转移保留诊断，不阻塞已支持的普通学习流程，也不放宽现有来源守卫。

继续按内容编译、纯规则、界面及连续流程并行分工；集成线独占 `GameState`、`GameSession`、存档版本与发布。每块系统验收一条完整连续流程，加失败、取消、重试和读档后的续行。

## 接续与批量填充

来源初始角色的完整系统入口和保存后续行已在 v73 闭合，v74 又完成世界旅行与实际内容批次的共同组合。接下来交付相连地图、事件与敌队的批次包，验证切图、剧情推进、菜单、两次战斗和读档继续。依赖规划汇总整组内容的初态、出口、条件和未用分支，所需缺口归并为共同接口；运行时不按地图名增加特例。world1来源出口与map3作者回程分别记录，未知故事旗标不因开发入口被补零。

战斗扩展使用同一行动/状态/参与者接口；世界旅行使用同一地图装载、交通与保存所有者；经济取得使用同一库存和交易事务。特殊效果由内容能力需求驱动，避免无限扩大骨架前置清单。

原生 Bird/FlatBird、调色板与海洋动态、车辆飞行/停靠、多队伍旅行、原生遇敌 lottery 和原版对照保持独立范围，不转回逐镜头工作。只有实际选定内容批次需要这些能力时，才以完整模块推进；实际浏览器结果另留证，合成接口测试与来源静态核对不替代它。

代表性组合通过后，成批编译区域、事件和敌队，并用留出路线验证同一运行时。一个批次的未知机制作为公共增量实施，不能跳过后计入可玩覆盖。骨架合同、来源批次放行、浏览器实玩和全游戏迁移分别留证；HD-2D 在完整 Web 迁移后开展。
