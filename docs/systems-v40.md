# v40 连续事件与新游戏框架

本批继续落实“游戏骨架优先”。沿用已有的 GameFlow → GameSession → WorldSession/FieldGame 和唯一 GameState，补齐跨脚本交接；增加独立开发内容配置，让纯环境粒子的缺口不再挡住新游戏流程。没有新增地图专用运行规则，没有继续粒子或 HD-2D 研究。

## 跨脚本事件

`ChangeScript` 通过同一编译器生成 `script-transition`。目标名称与 `Site.script` 来源名称分别保存；解析仍限于当前地图别名和明确 Resident 回退。替换脚本和单层调用后返回使用同一主任务与剧情状态，不重新创建队伍、相机或原生演员。

切换清理旧的任务槽和 Call 栈，并从目标脚本初始标签之后继续。返回只恢复调用者的局部变量 bank 和脚本进度；没有声明新局部变量的目标继续共享原 bank，新的选择结果不会被旧快照覆盖。原始事件的 SystemFlags 与演员生命周期保持到事件结束。未知目标、动画宿主、并发交互和嵌套返回在写入前显式拒绝。

尚未结束的返回式调用进入战斗或跨地图时，现有宿主交接不能携带调用者上下文，因此继续明确阻塞；不会静默丢弃调用者。本文连续框架轨迹先完成返回，再进入战斗。返回时仍有其他任务的未完成对话，也会在恢复调用者之前阻塞。

## 开发内容配置

`compileFrameworkContent` 从完整、摘要匹配的来源世界包派生 `framework-development-v1`。仅省略来源身份明确、匿名、没有交互/碰撞/脚本引用的环境粒子；逐项记录原包摘要、实体、来源和原因。其他粒子、未知属性和非视觉阻塞保留。它不创建假粒子 owner，也不改动剧情指令、角色或库存。

严格来源包仍在 `build/world` 与 `build/game/source-new-game.json`。开发包独立写入 `build/framework`，地图、目录和新游戏入口重新绑定摘要。`GameContentRepository` 显式选择配置；缺少开发包不会自动回退。存档仍使用既有版本，但内容身份与浏览器存储槽分别绑定，避免覆盖现有进度或跨配置误恢复。

```sh
npm run game:build
npm run world:build
node scripts/build-source-new-game.mjs
npm run framework:build
npm run dev
```

开发入口为 `http://127.0.0.1:4173/game/?profile=framework`，点击“从头开始（框架开发版）”。普通 `/game/` 保留既有入口。

## 验收边界

连续框架检查现在包含真实的跨脚本调用：对白 → 子脚本授予物品 → 返回 → 战败/重试 → 胜利/结算 → 菜单 → 保存/恢复。选择 UI 的受控链路也通过子脚本领取补给，再返回第二次选择和稳定检查点。

新游戏开发配置沿用来源初始化与原始事件，在受控媒体就绪输入下完成 609 → 3 的第一次地图事务。当前在 `sc_e_0001_1` 的第 38 条 `Move` 参数形式停止；这不是完整开场通过。严格来源配置依旧在目的地粒子提供器处停止，原版一致性和完整主线没有被标为通过。

检查入口：`npm run check`、Python 单测、`npm run framework:check`、`npm run event-interactions:check`、`npm run script-transitions:check`、`npm run framework-route:check`。具体当前构建结果见本地 `build/reports/v40-*` 与 `framework-source-route-check.json`。

最终构建通过 1,672 项 TypeScript 和 34 项 Python 测试、12 阶段连续框架轨迹、18 项系统集成、原有五次遭遇与 40 次检查点恢复。358 处来源脚本切换完成解码，3 条受控来源旅程与 3 项缺依赖检查通过；解码不代表这些剧情已可达。独立开发内容配置保留 371 条无法确认适用的效果，仅省略 495 条满足条件的环境效果；没有借此声明新增可玩地图覆盖。

浏览器在最终构建上实际完成选择 → 子脚本领取两瓶药 → 返回后第二次选择 → 退出事件 → 移动 → 内存保存 → 更换会话 → 恢复。最终选择值、剧情变量均为 2，药品为 2，位置为 `(38,48)`；没有改写用户的浏览器游戏存档，控制台没有警告或错误。截图保存在 `build/reports/v40-framework-browser.png`。这是受控系统验收，不能替代全游戏通关。
