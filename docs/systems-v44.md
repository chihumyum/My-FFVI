# v44 交通、骑乘与共享状态

本批继续搭建共用游戏骨架。交通是事件、演员、切图、字段规则与保存之间的一条完整状态链；没有新增地区内容，也不开展 HD-2D 或精细原生动画研究。

## 所有权与运行范围

`GameState.nativeState.ownedTransportations` 唯一保存来源交通记录的停车地图、位置、方向和 Int64 时间戳。是否启用继续由 `EventState` 的 release flag 决定。`FieldGame` 持有当前交通身份，`FieldPartyActors` 记账内外层资产，原生演员仍是唯一的姿态和动画所有者。候选准备失败、取消或过期时不发布另一半状态。

统一字段编译入口接入 `SetVehicle`、`RideVehicleNPC` 和 12 个交通系统调用。负角色选择器经既有来源绑定解析，不用它的数值直接索引实际玩家。启用/停车、玩家切换交通方式、某个 NPC 上下乘是不同命令；NPC 骑乘不改变玩家交通身份。

本轮玩家与演员执行限定在显式 `walking-magitek-framework-v1` 开发能力。原生普通地图合成器保留；骑手与载具由同一演员投影两层图像，骑手从外层现有时钟取姿态，不新增第二个动画状态所有者。原生速度、载具碰撞几何、随机遇敌表切换、交通 BGM、交通触发的状态移除、落地 UI、原版骑乘动画与脚部裁剪尚未实现；每条执行回执保留这些差异。`SetVehicle` 停车数据已保存，自动行驶 GPS/地图/时间戳回写仍未迁移。严格来源包不因开发能力通过就被放行。

普通上下乘、重新进入脚本、演员定位/移动、队伍外观刷新、跨图和稳定存档共用这些身份。NPC accessor 下车先恢复并清除骑手缓存；普通步行 Setup 的 Replace→RideOut 保留失活缓存。两种语义不能混写。

owned 快照升级至 **v10**，其 native 域为 **source-native-state-v2**。旧 v9 明确拒绝；field/world v9、session v4 保留。时间戳由宿主显式提供十进制字符串，确定性内核不读取系统时间。浏览器使用本地 `DateTime.Now` ticks 换算；受控检查使用固定输入。恢复不从保存数据取得时间宿主能力。

## 验收方式

专项合同见 [交通指令](field-transportation.md)、[停车记录](transportation-state.md)、[骑乘演员](field-transport-actors.md)。统一入口 `npm run framework:verify` 把交通连续会话与既有探索、事件、战斗、奖励、菜单、保存闭环一起回归。源码解析、受控会话、浏览器实玩和原版一致性分别记录；静态调用数量不转写成可玩场景数量。

本轮来源编译覆盖 277 处交通调用（42 处停车、171 处 NPC 骑乘、64 处系统调用），另 277 个非法保留位变体明确拒绝。12 个 selector 绑定有独立原生区段检查；这些结果不证明全部调用均已可执行。

## 本批验证结果

`npm run check` 通过 **1837/1837** 项 Node 测试及来源身份/合同校验；Python 测试 **34/34** 通过。字段、战斗、严格世界目录、新游戏和显式 framework 内容均已重新编译。严格目录仍为 649 条地图记录、533 份几何与 294 个默认实体组，这些是编译数量，不是可玩数量。
