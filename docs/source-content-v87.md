# v87 完整区域与共用战斗目录接入

基础骨架收口后，来源内容按完整区域及其依赖接入。南费加罗 `area_id=8` 的56张地图和135个来源入口属于同一生产范围；默认出口图包含两个各28图的连通分量，其故事时期与相互剧情关系继续未知。完整区域包保留几何失败、演员与指令缺口，不从集合中挑出可运行地图。

## 同候选的目录消费

此前完整敌队目录虽已生产，初始化地点包只有通过 v2 步行声明才使用它。普通事件战斗仍读有限来源目录，会重复得到缺失编组诊断。v3 配方把两个合同分开：

- `battleCatalogSelection` 明确选择 `source-baseline-v1` 或 `shared-framework-directory-v1`。
- `walking` 为 null 时不安装步行调度；显式声明时仍要求整个原敌队池具备执行资格。
- `sourceAreaScope` 为 null 或完整来源区域选择；不能靠过滤地图或成功路线声明完整区域。

`selectInitializedBattleCatalog` 验证原初始化、完整持有目录、共用规则、来源世界全图绑定及目录报告的相互摘要。框架目录完整复制，blocked 和 conditional 诊断不丢失。目录选择不创建角色、不改变剧情、不授予步行调度或原版战斗一致性。

`deriveSourceAreaScope` 从严格来源世界目录核对全部同区域地图，绑定每份原始包，保留初始化、来源入口、组、指令与提供器诊断、外部边界及未知世界阶段。验收从本次发布的原来源包重新构建收据，再与实际派生包全文比对。数据存在、声明路线完成与整批来源剧情准入保持不同结果。

## 生产与验收

公共集合继续通过 `npm run content-packages:build` 生成一个候选并一次发布。完整区域配方与原室内配方均在选择清单中固定原字节；v1/v2旧配方与旧内容版本保留，读档不隐式换到新目录或新初始化。

`npm run source-batches:check` 核对所有成员、完整原始正文、共用目录绑定和区域收据，再执行实际声明路线与存读档续行。骨架继续使用原有七个代表性检查器。新的56图集合只支持完整来源数据与依赖生产范围，不声称56图实玩通过或完整剧情迁移完成。

本批没有新增 NPC、特殊技能或视觉规则。范围和剩余依赖见 [南费加罗 dossier](../targets/south-figaro.md)，世界知识中的地点关联仍不授予故事时期。新鲜构建与验证结果保留在本地 `build/reports/v87-validation-summary.json`；全游戏目标保持 active，HD-2D 后置。
