# 共用实体组与地图生命周期

共用实体组、全量地图包与媒体编译、来源入口和切图请求已接入同一游戏内核。保存、完整相连地图流程、NPC/机关与全量事件仍未完成。地图数量是来源绑定范围，不是迁移完成率。

后续小地图批次已将同时满足几何/默认实体检查的地图从下文历史记录的 19 条增至 76 条，并实际完成 562 ↔ 563 往返。属性列表作用域见 [小地图批次](minimap.md)。共用 BGM 接入后，来源入口空闲数已达 54 个、分布于 27 条地图记录；最新口径与收据见 [背景音乐批次](bgm.md)。

## 模块与边界

- `src/compiler/map-package.ts` 按资源组、地图名和包内别名解析精确引用。脚本先查当前地图，再查原程序明确指定的 `map_script/Resident`；不按全局同名文件猜测。重复别名、缺失已声明资源和有歧义的包保持阻塞，不能借公共脚本掩盖损坏的本地引用。
- `src/compiler/table-id.ts` 按 int32 解析主表 ID；原始 CSV 行不修改。原表存在尾部空格，用字符串直接关联会漏掉数百处初始化脚本。重复数值身份仍报错。
- `src/compiler/entity-group.ts` 将来源对象坐标、层、实体身份、入口 ObjectId、目标地图和触发脚本归一化，保留逐对象来源。支持底层对象层；未知层留下阻塞，同时保留其他层的入口候选，不把整份来源误报为空。
- `src/core/field.ts` 持有当前实体列表和已激活组。新组整体校验通过后才加入角色、碰撞和触发器，后续输入使用这份列表；失败不能留下部分状态。原始编译内容不被修改。
- `tools/source_adapter/export_world_media.py` 按包内精确路径导出地图图集和角色 Sprite，保留来源与缺失项；图片以内容摘要命名。`src/compiler/map-geometry.ts` 同时服务原有纳尔谢回归与全量地图，拒绝未知坐标变换、图集越界和碰撞值。
- `src/compiler/world.ts` 生成目录与 649 个地图内容包；角色动画缺失、重名和特殊 shader 保持诊断，受影响姿势不能在运行时悄悄替换。
- `src/core/world-session.ts` 拥有当前 FieldGame、切图准备与提交；GameSession 保留队伍、战斗、Gil 与奖励。BGM 状态在准备阶段复制，原会话音乐变化会拒绝过期提交。浏览器校验内容摘要并加载所需图片和音乐后提交，不在渲染层更改剧情状态。

原生 `SetEventEntityGroup` 追加实体，并非替换当前所有组。原生实体管理器对非零 EntityID 有去重行为，但其他列表仍可能追加；重复激活和跨组身份冲突的完整行为尚未恢复，因此当前明确停止。原生当前属性列表另按“默认组 + 最新组”重建，不等同于实体追加；相关特殊碰撞、区域和表现机制不能因普通实体能加载就视为已支持。

归一化认识入口、普通进入触发器、切图点、层切换、简单静态角色和无条件碰撞。普通 GoToMap 动作（action_id 3）和脚本 ChangeMap 产生同一种加载请求；附加脚本、机关、路线绑定和交通条件不明的切图点仍阻塞。NPC 的交互、推动、受影响移动、自主路线、跨层和鸟瞰行为尚未完整实现，依赖这些行为的组保留阻塞。多边形、旋转和未知实体种类也不降级成近似矩形。媒体就绪与逻辑就绪分别检查。

此前已实玩的纳尔谢开发检查点继续保留其已声明的固定组、静止 NPC 和特殊对象省略；没有把这套近似推广到新组。新 `SetEntities` 激活必须通过完整组检查。该检查点仍是回归样本，不能当作任意地图的初始化方案。

## 来源规则

仅针对当前来源：DLL `1a7e12c90c6a734e17dda507dd6ab7555090dff6a1e96f3473a90c29916ca6dc`，metadata `9b426d617a022020feee61cdfc19b16ce1a51c07542fe1dd59169e12f35a3e45`。忽略目录中的导出收据核对了原生文件、符号和方法范围摘要；反编译仍属静态证据，不是原版运行对照。

| 规则 | Native RVA / 定位 |
| --- | --- |
| SetEntities 读 `s[0]`，转发地图组激活 | `0xB48CF0` |
| 按精确组名查找、启用，追加实体和碰撞列表 | `0x3529B0`、`0x352FB0`、`0x2ED6F0` |
| 当前属性列表按默认组和最新组重建 | `0x353370` |
| 非零 EntityID 去重和后续注册列表 | `0xAAFB90`、`0xAAFE70`、`0xAAFF10` |
| 地图初始化名称来自 map_script 主表，区别于普通事件的 script 主表 | `0x352B80`，结合 Map.ScriptId / MapScript.Param 类型 |
| 当前地图脚本查找失败后查常驻脚本 | `0x352CA0`、`0x2DBA40`、`0x30C300`；MapManager 的 Resident 常量 |
| 进入时先尝试保留的后继脚本，未运行才尝试普通地图初始化；没有脚本可以继续 | `0x58A910`、`0x7AD6C0`、`0x2CCAC0`、`0x5F2530` |
| ChangeMap：`i[0]` 地图，`i[1]` 入口，`i[2..4]` 分别为鸟瞰、跳过淡入淡出、跳过 BGM；`s[0]` 后继脚本 | `0xB4F500`、`0xB512D0`、`0xB51B60`、`0x2FB180` |
| 入口先筛 ObjectType 0，再匹配 ObjectId，不能用 EntityID 或 Tiled 对象编号代替 | `0x30F140`、`0x366430` |
| 同区域切图清地图变量；换区域且此前区域 ID 大于 0 时清区域及地图变量 | `0x2E39A0`，调用 `0x82E870` / `0x82E810` |
| GoToMap 动作以 PropertyGotoMap 生成普通视图 LoadData，再调用 EventGotoMap(false,false) | `0x7AF9C0`、`0x2FB2F0`；角色进入条件 `0xAEDF30` |

`ChangeMap` 的目标、后继和局部变量规则现已执行，保留请求的来源及全部视图/淡出/BGM 参数。鸟瞰视图仍拒绝；淡出、自动选曲与完整交通工具生命周期明确属于未完成表现。显式 PlayBGM / StopBGM 和播放位置继承已接入，仍不能据此宣称 skipBgm 等完整切图音频规则已经恢复。开发运行保留当前队伍外观，不据此宣称车辆状态正确。初次区域 ID 为 0 时原生不走区域清理路径，不能自行用全零状态覆盖未知检查点。

新场景在状态副本上选择默认实体和唯一 PointIn，再启动后继或初始化脚本。准备阶段失败不改旧场景或变量；成功后才切换持有者。持续事件可在新场景继续等待或对话，之后遇到未知指令会明确停止，不能把“提交成功”当作初始化全程完成。提交验证原 FieldGame、原请求、原状态和目录身份，拒绝过期请求、重复提交、异步加载期间的状态变化和会话中的内容版本漂移。浏览器重开会话另有 owner 检查。

研究输出位于 `build/native/map-lifecycle/`、`map-entry/`、`point-in/`、`map-script-entry/`、`map-script-fallback/`、`map-event-entry/`、`map-trigger/`。完整导出不等于每条反编译表达式都已恢复，尤其共享 RVA 的类型别名须结合声明和实际调用判断。

## 批量检查

```sh
npm run maps:check
npm run corpus:plan
npm run world:build
npm run world:check
```

`map-index.json` 绑定 649 条地图记录、1,695 个地图内实体组引用，对应 1,629 个独立来源实体组。530 条地图记录解析到初始化脚本，111 条登记了名称但本地和常驻包均未声明，8 条未配置。后两类保留不同状态；不能把“已声明但文件缺失”归入它们。空的可选地图字段保持空，不尝试加载名为 `.json` 的虚构资源。

3,373 处静态切图引用中，3,369 处找到唯一默认入口，4 处仍缺少匹配入口；原始后继脚本和来源位置保留供后续调查。这些入口候选不证明地图初始化、剧情可达或切图后的表现正确。入口动态激活、车辆和特殊地图仍需生命周期实现。

当前 160 个组引用没有已识别的逻辑阻塞，仍不代表媒体或地图可玩。整批执行检查在运行前按能力与全部组依赖筛选，使用同一个 FieldGame：4 份独立原始脚本在 5 个地图上下文中执行 10 组受控输入，均正常结束，7 组实际激活实体；所有 5 个地图脚本上下文都出现随 flag 变化的激活分支。两个地图记录复用同一来源脚本，不重复计为两份源脚本。

收据为 `build/reports/entity-group-check.json`；未选脚本与排除原因也保留。检查宿主不加载默认实体、图片或真实存档，所以结果仅证明受支持的分支和组激活能在新内核执行。此前宽松筛选得到的 16 个上下文不再作为通过量：补上 NPC 行为阻塞后，适用集合主动收窄。

## 全量媒体与地图装载批次

媒体适配器从 515 个来源包导出 209 个地图包的 394 个图集引用、306 个角色包的 2,443 个 Sprite 引用。地图图集未留缺失引用，角色仍有 184 项缺失或裁切几何需求。source-set 为 `8e6eec80ea75e69922dac1d42a9f4f34bc7f939c302151792ee7c121440f7fa5`；再次从实际源导出完成。保留图集存储行序，不把少量浏览器观察推广为所有地图视觉一致。

649 条地图记录均生成包。加入共用静态斜角和 MapRange 后，524 条通过当前几何与包引用检查（此前 395），26 条默认实体无已识别阻塞（此前 12），两者同时满足的有 19 条。批量加载器对其 30 个默认入口实际准备/提交：4 个地图记录共 6 个入口到达空闲状态，24 个入口因初始化指令、未知剧情状态或坐标/层尚不支持停止；另 630 条按依赖缺口排除。输入使用开发队伍和未知剧情状态，没有编造后期存档。

此前 Map_30871_3（map_id 545）已有浏览器加载、移动及目标未就绪时保留旧图的证据。本批新增 Map_20171_3（map_id 122）：来源入口 1 为 (57,15)，实际按键移动至 (57,12)，显示正常、控制台无警告/错误；来源 MapRange 让小地图相机正确居中。截图 `build/reports/collision-map-browser.jpg`。没有完成这两处的相连地图往返或区域剧情；其他成功入口仍只有无界面执行证据。

`build/reports/world-check.json` 保存所有尝试和排除原因，按几何与默认实体能力汇总阻塞。浏览器入口 `/game/?map=<ID>&entrance=<ObjectId>` 明确标记为开发预览。游戏资产、剧情文本、地图包与截图继续留在忽略目录。
