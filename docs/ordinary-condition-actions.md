# Ordinary source condition actions

The frozen absorption baseline has 1,530 abilities / 537 bounded plans, all 474
AI master rows (423 complete bodies, 51 absent bodies), 211 learning rows and all
53 battle programs / 2,312 instructions. Function9 appears in 564 abilities:
528 single-function bodies and 36 mixed bodies. Of the single bodies, 274 have
the exact ordinary None(0,0,0) process. None of these denominators is filtered
to make the acceptance rate look better.

This family closes the standard single-slot condition action carrier: direct
application by Function9, single-row removal by Function11, and ordered group
removal by Function12. An incoming condition must already have a positively
implemented lifecycle. Recovery references can be inactive unknown behaviors;
they cannot make an unknown active state legal. Original function slots, source
IDs, all rules, process values, forbidden groups, flags, elements and effect/SE
masters stay bound. A versioned Web declaration carries the complete original
typed program and fails if a later program or declaration changes.

Existing action and condition owners perform payment, target selection, RNG,
resistance, conflict resolution, control clocks, reactions and life settlement.
No second queue, condition owner or settlement path is introduced. Ordinary
input, AI, scripted and derived actions enter the same path. Unknown phase,
equipment, condition and resource dependencies remain reported stops.

Function9 Value1 is the condition row ID; Value2=1 bypasses evasion, but still
rejects outer resistance value1. Ordinary Value2=0 rejects a resistance key even
when its value is zero. Value3 remains zero. Flag1 bypasses evasion; flag3 keeps
its source Runic target meaning, with active Runic still outside admission.
Function11/12 remove one record per requested row, preserving source group
order and repeats. A declared ordinary recovery without any current requested
condition produces native Miss2, consumes no RNG and cannot wake a hit-only
reaction. This corrects the earlier same-family recovery approximation. Source type5/undead and other native overrides remain gated;
this carrier does not implement death, stone, zombie, Stop or mixed-effect
sequencing. Existing explicit range16 control cases retain their original
policy; this family does not generalize that range.

The explicit web-source-ordinary-condition-action-deferred-v1 declaration keeps
the original effect and sound dependencies while deferring native playback.
The existing 400/900 ms stages and actual status text are the Web continuation
policy, not native animation timing. The old undeclared condition shape remains
compatible. A save cannot create this content declaration or grant an ability;
only the existing settled field return is saveable.

Acceptance separates full source auditing, actual source-operand actions in
authored envelopes, shared-owner Session/Storage checks, static cached-native
proof, App/BattleView checks and original story execution. A newly compiled
plan is not a claim that its original AI body or a whole story path has finished.
The parent owns the single subsequent world producer and source replay.

The private delivery census produces 558 bounded plans: 21 new plans, no lost
plans and one corrected earlier same-family plan (source 763 receives the
matching-current-condition-or-miss policy). Every other previous plan is equal.
The new plans have 43 references in 26 complete AI bodies and 16 learning rows;
these references do not grant ownership. The compiler binds 119 complete
ordinary declarations, while all 546 single Fn9/11/12 bodies and all 564 Fn9
bodies remain visible in the audit, including every blocked combination.

Fourteen family tests cover ordinary input, source control policy, normal and
derived AI, fees/RNG/resistance, group order, true Miss reactions, same-frame
message/effect/shared-variable failure and retry. Two actual Session cases
cover application, Fn11/12 cure, media failure/cancellation, stable owned return,
quota failure and Storage restoration. The complete core suite has 4,347 tests;
30 actual App and four actual BattleView cases run on the same runtime. All 21
new original operand actions execute in authored envelopes. No original AI or
story program is counted as completed.

Static cached evidence is independently checked as the existing broader
73-method / 52,928-byte control packet and a finite 14-method / 11,680-byte
Fn9/11/12 packet. The packets overlap and their counts must not be added. The
finite packet binds the single/group Hit0/Miss2 selection, recovery controller,
life/undead guards, complete original PE ranges and every shared alias. No new
Ghidra export, native execution or source-world producer is required here.
