# Source Skybox clock and explicit Web panorama

The census retains all 3,304 programs and 186,003 instructions. The complete background/scroll nomination contains 78 bodies, 14,549 instructions and 133 sites: 128 Field sites and five other-domain sites. Its 53 registered related selectors keep every shared alias. This delivery implements the two source Skybox wrappers as one parameterized capability; the other 131 sites still retain their existing concrete owner gates. Scenery Show/Hide, layer scroll and battle background calls are not Skybox calls.

## Native contract

The two wrappers read Unity's float32 time into their actual Core.General `r0` on first clock. Every clock computes a clamped float32 ratio, interpolates a texture offset, calls the common Skybox owner and returns Wait until the ratio reaches one. The opening request is 115 seconds, offset 0 to -100; the imperial request is 37 seconds, -4 to -134. Neither is an instant visual action. The original operands remain untouched, including zero padding.

The opening wrapper also selects its original literal secondary resource `Map_40000_other` and creates 920 linear keyframes at 0.125-second intervals, alternating 0 and 0.75. The final 0.75 is retained. Ghidra incorrectly prints zero as the KeyFrame value argument; the complete PE passes xmm6. Native InitMap binds `map.name + "_normal"` only for actual world-area maps. Selecting a secondary changes the native current model key, but primary texture ownership remains distinct. All 18 model rows, 18 full Texture images, Sprite/Texture identities, sampler metadata and original material are retained. The Sprite render rectangle can be cropped while the underlying Texture is complete.

The bounded evidence contains 22 methods and 6,224 PE bytes, plus the previously cached full InitMap method. It is static evidence, not an execution of the original game. The checker verifies the complete native DLL, symbol/header identities, method intervals, C hashes, literal and the erroneous KeyFrame call against the PE.

## Web contract and authority

`web-flat-skybox-panorama-v1` is a deliberate 2D display policy. It is required both in current trusted content and in GameSession runtime ports. A save cannot supply either authorization. A single Field-owned Skybox state carries the model names, offset and current blend curve. The existing source Task retains first-clock `r0` and waits on that same state. Concurrent Tasks retain their own Core banks; source scheduler order determines successive writes to the shared offset. A later crossfade replaces the common blend curve, as the native owner does. No PC, source-program ID or map ID controls execution.

This Web policy uses the published current Field's fixed 10 ms clock. Private I/O candidates and retired Fields cannot clock or publish. Battle pauses this Field domain, including its presentation. This is an explicit Web difference from the native global Unity/BirdView update domains; no native timing equivalence is asserted. Battle passive audio/timer domains remain independent. Active source waits reject root replacement, map/battle transfer and saving through the existing unfinished-interpolation boundary.

The renderer samples the original complete Texture in a reserved top-third panorama. The source numeric offset is interpreted in Texture pixels, primary/secondary samples blend by the retained ratio, and point/linear sampling plus clamp/repeat follow the declared 2D sampler. Native trilinear filtering reduces to bilinear on this flat unscaled texture. Native 3D mesh, sixfold texture scaling, fog layers, shader geometry, rotation and height-margin composition are retained as metadata but omitted from this Web display. Background/ground tile fragments are clipped out of the reserved display band; actors, legal actor coordinates, interaction markers and UI are drawn afterwards with their existing projections. Collision, source event coordinates and logical camera coordinates do not change. This explicit display crop prevents an opaque ground tile from hiding every Skybox pixel.

A reached request with missing/ambiguous models, unknown defaults, textures or positive native effect dependencies stops with its original dependency gate. In particular the actual imperial source model requests effect 306; its complete source map is still blocked. Pixel checks for that map are only parameter/media/compositor evidence and do not grant whole-map admission. The original shader's unresolved external identity is preserved and explicitly deferred by this Web policy.

## Content, lifecycle and save boundary

`loadFieldSkyboxCatalog` verifies the media snapshot and every PNG digest, exact miscellaneous source asset/models, physical source manifest and all Sprite/Texture identities. Public framework derivation and the selected-source producer attach the same catalog only where the real Map/Area rows prove world applicability. The original strict source maps are unchanged. Formal recipe upgrades require exact `compiled-framework-profile-upgrade-v10`: complete v9 markers, the Skybox marker, and the exact independently loaded source catalog. Versions 1–9 keep their previous exact shapes. Geometry, other media, script bodies and old provider definitions cannot be normalized by this declaration.

The prerequisite input lock is separately versioned v3 when Skybox is requested. It binds the full media snapshot and original two source bundle fingerprints, including real paths and lengths; v1/v2 shapes are unchanged. The common public App and replay ports use the same explicit runtime marker.

Stable numeric Skybox state is an optional child of the existing native Field checkpoint, with exact binding to content/map/catalog/source domains. Old native checkpoint shapes remain unchanged when the capability is absent. Active Task/curve state, callbacks, foreign bindings, or missing current runtime/content authorization cannot restore. A ready Skybox without an actual native map checkpoint owner refuses save instead of losing the pose. Failed/cancelled media preparation preserves the old current Field and owned domains; publication retires old/private owners, and late completions cannot revive them. Source instructions still commit individually after publication; no new multi-clock or whole-scene rollback is claimed.

## Verification

Run the normal TypeScript/core checks, `node scripts/check-source-skybox.mjs --before-compiled-dir <baseline-dist>`, `node scripts/check-skybox-renderer.mjs`, and `python tools/native/check_source_skybox.py --evidence-dir <retained-native-packets> --report build/reports/source-skybox-native.json`. The source audit loads the complete source once, preserves complete bodies and map/media/dependency closures, and compares every instruction with the baseline compiler. It executes the two unmodified original operands in real authored Session envelopes through their full durations and stable restore. These are not complete original program executions, a campaign playthrough, browser acceptance or Unity pixel parity.
