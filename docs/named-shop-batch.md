# 命名商店的整批接入

本批按同源 SysCall 字典和商品组接入全部剩余17个命名商店 selector，复用既有 FieldScriptShop、交易、库存、Gil、关闭后续行和保存系统。没有按商店或地图复制交易代码。原有8个南费加罗绑定继续保留；25个绑定及49个原始参数使用点由同一次来源审计核对。

`scripts/inspect-named-shop-bindings.py` 逐一读取来源字典注册、确切字符串、方法元数据及包装器中的商品组字面值，核验完整固定 DLL/符号/头文件和已有共用商店方法回执。费加罗不同阶段、左右柜台及领队变体保持独立商品组。原方法的英文名不会替代实际字典身份，未被原脚本调用的魔列车商品组不会因此获得绑定。

`scripts/named-shop-bindings.mjs` 另外将编译结果与独立原生审计、完整来源商品组表核对。修改绑定、重复 selector、缺失商品组、未知 selector 和未准入操作数都拒绝。通过字典核对只授予类型化绑定，不授予宿主可用性、剧情时期或主线可达性。

完整源程序验收使用独立计算的依赖闭包，保留物理文件相同正文在不同地图命名空间中的身份。候选通过现有内容仓库、来源初始化、会话、Flow、Commands 和检查点系统运行；实际源脚本仍负责分支、对白、开店和关店后的原PC续行。起始放置与媒体确认属于受控输入，剧情旗标不由检查器补齐，缺少可信后期状态的分支继续未评估。额外行商程序的消息行内控制和路线依赖仍有缺口，不计为整段可玩。

完整生命周期检查另行记录真实交易、余额和库存增量、拒绝越界交易、关闭一次、陈旧命令、配额失败和重试、恢复后复访。私有编译候选与实际公共发布分别留证；未通过的来源入口、演员生命周期和故事可达性门槛不能由绑定数量掩盖。完整Web迁移goal继续进行。

当前私有同源候选自动发现9个根/41个原使用点；8个根的可解码依赖闭包为11份物理程序、826条指令、7图、40个使用点、16个 selector及220条已解析边。实际16个生命周期案例中12个通过，另4个莫布里兹案例在原地图初始化阶段因scriptPuppetContexts缺失被拒绝；额外第9个根的完整消息/路线缺口也保留。通过案例不授予后期世界分支或完整原剧情的可达性。

`npm run named-shops:assess` 默认只读当前公共来源包；未由本批编译器生成的内容保持unready。`node scripts/check-named-shops-lifecycle.mjs --compiled dist --source-compiler dist` 可通过同一纯编译器生成私有完整来源候选验证共用owner，不写公共集合或刷新配方pins。缺失脚本旗标的真实导入协议正在独立按全源家族核实，当前不会由检查器补默认值。
