# 公共战斗状态、反应与动作事务

继续按用户的系统骨架优先要求推进。已有标题、探索、事件、世界旅行、战斗、奖励、菜单与保存使用同一会话；本批补共同状态和 AI 能力，不逐场景恢复演出，也不开展 HD-2D。

## 状态所有权

初始敌人、不可变怪物模板与当前战斗实例继续分开。`compileEnemyInitialConditions` 绑定完整来源组与状态 master，初态由实际入战阶段激活，不经过技能施加的命中、抗性或冲突判断。重复组成员不会复制同一 master。多个初态的激活顺序及 group/master 身份冲突保持阻塞；增援和换轮不能借用首次入战的阶段许可。

状态93/94保留来源身份，复用现有物理/魔法防护计算。其关联组是临时抗性字典，不能解释为追加普通状态23/22。`BattleConditions` 从当前实例的 `conditionIds` 派生临时抗性，移除、死亡及战末恢复后自然消失；没有第二个可变抗性 owner。敌方临时字典优先于基础字典，玩家冲突的未知优先级仍拒绝。普通技能施加的旧资格不会随初态能力扩大。详见 [状态合同](initial-protection.md)。

177个非零初态怪物中，26个获得此项单防护初态能力。这是状态依赖准入，不能当作可玩敌队或剧情覆盖。

## 施加者与目标分开

函数38的共同接口保留状态 row/type、三槽顺序、原参数、固定/更新阶段、添加/删除和独立 CalcResult。全部13条来源记录可严格解码，只有696的完整组合获准，其余12条仍保留生命周期、复合动作或其他能力缺口。

`projectActionTargets` 承接完整目标组的准备；本批只准入一个固定阶段的施加者删除效果及已证实的空主结果字典。函数按名义目标逐次投射同一份私有施加者状态，目标自身状态与施加者状态不互相覆盖。空主字典不是0伤害、命中、未命中或 Non；独立用户 Non 结果不能冒充目标结果并触发反击。

全部目标、施加者状态、费用、状态时钟、AI、队列、日志与随机流通过原 `BattleGame` 事务提交。后续目标或提交过程失败会回滚同一逻辑帧，保留实际单位身份。自身目标也只支付一次费用。活动682、未知添加/死亡组合、多用户 wrapper 顺序和更新阶段没有因此获准。

## AI 与批次入口

来源 `IsReceiveCommand` / `IsCheckReceiveCommand` 实际查询收到的能力 `TypeId`，与命令 master ID、能力 ID、system ID 分开。共同 received-ability 上下文携带可选 `typeId`，空接收引用按原 getter 返回0；旧调用缺少元数据时，仅在实际到达类型判断后明确失败。达到 `SyncAI` 后一并清除身份，不能带入下一回合。两个来源键共186站点、38个来源 AI 脚本，其中184个条件编码可用此接口；另2处越界目标和额外操作数仍阻塞，不能解释为38个完整 AI 已可玩。

批次声明v2增加显式开发入口策略，复用原阵型、脚本及旗标开发合同。每项省略绑定实际完整来源摘要；错误、变化、冲突或未使用的绑定拒绝整个批次。旧v1声明与严格来源入场不受该策略授权。省略不会修改原脚本、旗标或初始资源，也不会授予原剧情可达性。

`content-batches/narshe-battle-systems.json` 保留set129全部4个正权重敌队。严格原入口仍因来源脚本、旗标及阵型等依赖阻塞。显式开发入口下，275仍缺反击目标范围、`CounterPlayerAct` 与能力327的完整效果；整个批次继续拒绝发布，没有删去该队后宣称池已迁移。

129/274/276另作独立系统探针，不替代完整池。其来源敌人32级，当前低级开发队伍在不改数值、角色、装备或库存的情况下正常战败；共用检查器验证真实命令、入场/重试媒体失败、持久资源和奖励不被败北污染、同一入场的重试及旧操作拒绝。胜利、一次结算、返回、保存恢复继续由原普通战斗批次和完整骨架流程回归。

## 验证与接续

执行 `npm run check`、Python工具测试、`npm run framework:verify`，以及必要的当前来源生产和摘要更新。新增 `npm run battle-systems:check` 会分别检查状态来源合同、完整池拒绝与独立动作探针；统一框架检查调用同一脚本。报告保存在忽略的 `build/reports/`，原始资源及原生导出不入Git。

受控接口、来源静态绑定、内容批次发布、真实浏览器游玩和全游戏迁移分开记证。完整迁移 goal 保持 active。后续优先 NPC 自主活动与事件接管这一公共模块，再按完整依赖接入区域内容；不把反击的单个 PC 或演出指令升级为逐条迁移主线。
