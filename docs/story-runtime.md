# 共用剧情运行时批次

本批处理全量来源语料中的普通计时/到期回调、BGM 暂停/重播、ColorFade/Flash 和普通镜头 Move/MoveTo 家族。来源地图名、剧情旗标、坐标和曲目都是输入，不是运行时分支。HD-2D 和严格原版对照继续后置；完成这些共用能力不代表完整主线可达。

同批的 [AutoSave Web 保存屏障](field-auto-save.md) 复用已有保存协调器、当前/上一份存档及事件续行。它采用独立可信 marker：首时钟等待，下一时钟请求保存，写入成功后续行。原版的玩家/演员/镜头同步、AutoSlot 和异步保存时点仍未迁移；来源站点保留这种差异的需求记录，不计为完整原指令验收。

## 状态与发布

`FieldGame` 保有一份计时状态和一份颜色过滤状态。Flash 委托已有 `FieldFadeState`，镜头路径通过已有 `FieldCameraHost` 发布；等待阶段只在已有 VM task 保存游标。音频控制仍使用已有 `StaticAudioState`。没有另一个剧情 VM、队伍、剧情银行或音频时钟。

所有框架派生包声明 `storyRuntime: web-field-story-runtime-v1`；严格来源包保留宿主未评估状态。marker 只允许明确的 Web 策略，不能由存档自行补入。计时采用逻辑毫秒，ColorFade 采用普通字段的线性 RGBA 覆盖层；原版 shader、BirdView 和精确混音曲线没有因此获得一致性验收。

## 计时与回调

SetTimer 保留四个来源选择器和所有非空回调名。显示选择器0显示 UI；战斗选择器0允许战斗计时；消息选择器1允许消息期间计时；事件选择器1允许事件及 gimmick 期间计时。普通玩家计时始终启用。多个回调的随机选择、特殊 Cid/Shadow 计时和未知选择器继续阻塞。

启动时从可信内容解析确切的原指令和回调来源。暂停/恢复不改变剩余时间；FinishTimer 或重新设置使旧回调代次失效。到期仅形成待发布请求，成功建立已有 VM 根任务或替换主脚本后才确认一次。对话、战斗及切图期间不会任意抢占字段任务。

切图候选复制状态与可信来源元数据；取消、准备失败或候选过期保留原 owner。提交前核对原字段及候选字段的状态。战斗由 GameSession 推进同一计时 owner，UI 仅读取其投影。

活动计时可以稳定保存，保留剩余时间、暂停、到期和派发状态。恢复按同一内容目录重新读取独立可信的来源地图或初始包装，重新绑定原 SetTimer 及回调；存档中的脚本内容不能提供权限。跨图回调仍须存在于当前可信脚本命名空间且来源相同，来源图专属程序不会被擅自当作另一地图的程序执行。

## 音频与演出

PauseBGM 的 i1 是暂停/恢复，淡出完成后冻结播放样本；恢复继续该位置。ReplayBgm 固定主通道，第一逻辑时钟保留曲目并停止，下一时钟从零重播。它是已有 VM task 的短期游标，未完成时不能保存。真实 AudioOutput 根据暂停投影撤下输出节点，恢复时重新安装；页面暂停和声音静音仍由原 UI 管理。

ColorFade 零时长立即完成，负时长异步继续，正时长等待已有颜色 owner 完成。Flash 使用已有 fader 的 out/in 两阶段，即使零时长也经过各自时钟。活动演出不能进入稳定或事件保存；镜头 Move/MoveTo 的未完成路径同样阻止切图、替换脚本和保存，不丢弃游标来继续剧情。

镜头路径支持普通非循环地图、七档来源速度及有确切来源位置的 MoveTo，保留 camera dummy 的原 Z。每个路径段在后续时钟排空，不用一个大帧跨过多段。动画、未知 raycast/回调、循环地图及换层需求继续明确阻塞。

## 整批验证

编译器保留全部源地址；SetTimer 的所有候选回调进入依赖图，包括未支持的随机分支。实际宿主需求通过 `storyTimer`、`screenEffects` 和已有镜头/音频能力评估，未知、缺失和可用分别记录。

合成的连续 VM/World 用例验证对话与选择暂停、到期一次、真实战斗计时、切图取消、候选失效、可信来源恢复、音频输出生命周期、转场等待及事件保存屏障。源家族检查另外保留全部源使用点与失败原因；参数执行不冒充完整来源程序或通关。

公共内容只通过一次候选/发布管线重编。本批之后重新执行 `story:check` 的完整语料和世界规划，并以刚发布的可信引用执行新游戏流程。完整主线、分支、支线与结局尚未完成，第二 goal 保持进行中。
